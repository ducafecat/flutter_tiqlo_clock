# 像素风组件规范

本文定义 Tiqlo Clock 的 Flutter 像素风 UI 标准。新页面和新交互应优先复用现有组件，而不是重新绘制边框、阴影、按钮状态或响应式逻辑。

## 1. 使用入口

```dart
import 'package:flutter_tiqlo_clock/core/ui/ui.dart';
```

`core/ui/ui.dart` 统一导出页面响应式布局和 Pixel UI 组件。仅在必须使用底层绘制、形状或内部样式时，才直接 import `core/ui/pixel/*`。

## 2. 视觉基础

### 2.1 主题与 Token

应用主题必须使用 `PixelTheme.darkTheme`。颜色、间距、描边、硬阴影、交互动效和字体均从 `PixelTokens.of(context)` 读取，不在业务页面写重复的色值或动效时长。

| 类别 | 标准 |
| --- | --- |
| 页面底色 | `tokens.chrome` / `tokens.chromeHighlight`，由 `PixelPageScaffold` 统一绘制 |
| 常规面板 | `tokens.surface` / `PixelPanel` |
| 高亮面板 | `tokens.surfaceHigh` |
| 主文字 | `tokens.textPrimary` |
| 分组标题 | `tokens.section` |
| 主操作 | `tokens.accent` |
| 危险操作 | `tokens.danger` |
| 轮廓与硬阴影 | `tokens.outline`、`tokens.hardShadowOffset` |
| 焦点态 | `tokens.focus` |

默认间距单位为 `4 / 8 / 16 / 24`，分别使用 `spacingXs / spacingSm / spacingMd / spacingLg`。不要引入与这些节奏无关的随机间距。

### 2.2 字体

| 场景 | API | 默认字体 |
| --- | --- | --- |
| 页面标题、常规正文 | `tokens.heading()` / `tokens.body()` | PixelifySans |
| HUD、小型像素标识 | `tokens.hud()` | Tiny5 |
| 翻页时钟 | `tokens.flipDisplay()` | Jersey 25 |
| 数码时钟 | `tokens.digitalDisplay()` | Doto |

文字必须通过 token API 生成，以保留中文回退字体和统一行高。

### 2.3 Board 边框规范

选择项、操作项与色彩选项统一称为 **Board**。必须通过 `PixelThemeOptionFrame` 绘制；禁止以 `Border`、`BoxShadow`、圆角 `Container` 或复制一套偏移边框的方式自行实现。

| 项目 | 标准 |
| --- | --- |
| 正面结构 | 仅一层深色外框、一层状态描边与一层面板填充；正面边缘不得出现平行双线 |
| 选中描边 | `optionOutlineSelected`（`#B8B9B5`） |
| 默认描边 | `optionOutline`（`#41423E`） |
| 正面填充 | 默认 `#1D1E1D`，选中 `#242624` |
| 右侧/底部阴影 | `1dp`，使用 `optionDepthShade`（`#151614`）；阴影是连续实体，不能再画第二套轮廓 |
| 外角 | `6dp` 切角，由 3 级 `2 × 2dp` 小方块阶梯组成 |
| 描边内角 | `4dp` 切角，由 2 级 `2 × 2dp` 小方块阶梯组成 |
| 填充内角 | `2dp` 单级小方块切角 |
| Board 间距 | 主题样式选项为 `4dp`；色彩选项按 `PixelThemeSheetStyle.optionGap` 统一设置 |

锯齿角只能使用 `pixelCutPath` / `PixelCutClipper`。该路径只包含水平线和垂直线，禁止使用斜线、`BorderRadius` 或抗锯齿圆角。下图对应的角点顺序为：

```text
      ┌────────
    ┌─┘
  ┌─┘
──┘
```

实现时，先绘制包含右下 `1dp` 厚度的连续实体，再绘制一次正面外框、描边和填充。这样既保留像素厚度，也不会在右侧、底部形成双层边框。

## 3. 页面响应式标准

### 3.1 必须使用 `PixelPageScaffold`

所有带页头的二级页面（例如 Settings、About，以及后续的帮助、隐私、详情页）使用 `PixelPageScaffold`。它在内部组合 `Scaffold`、标准页面背景、`AdaptivePageFrame` 与 `PixelPageHeader`，业务页面只提供正文。

```dart
PixelPageScaffold(
  title: 'Settings',
  onBack: onBack,
  portraitMaxWidth: 426,
  builder: (context, layout) => YourContent(layout: layout),
)
```

它负责以下规则：

1. 包裹 `SafeArea`；页面不能重复包裹第二层 `SafeArea`。
2. 竖屏内容宽度为 `min(屏幕可用宽度, portraitMaxWidth)`，并水平居中。
3. 横屏内容宽度等于完整 Safe Area 宽度；不能再写横屏 `maxWidth` 上限。
4. 通过 `AdaptivePageLayout` 提供 `isLandscape` 与 `contentWidth`，由内容决定分栏和内边距。

当前页面的竖屏阅读宽度：

| 页面 | `portraitMaxWidth` |
| --- | ---: |
| Settings | 426 |
| About | 720 |

### 3.2 横屏内容规则

横屏使用完整页面宽度，内容左右使用统一的 `24dp` 边距。竖屏通常使用 `16dp` 或 `18dp` 边距，保持紧凑阅读体验。

重复分组应按照可用宽度自动平铺，不应继续固定成单列。Settings 的标准实现为：

- 分组间距：`25dp`；
- 单个分组最低宽度：`350dp`；
- 字号放大时提高最低宽度，自动减少列数；
- 列数限制为 `1～3`；
- 任何宽度都必须允许垂直滚动。

示例：

```dart
final columns = layout.isLandscape
    ? ((layout.contentWidth + gap) / (minTileWidth + gap))
          .floor()
          .clamp(1, 3)
    : 1;
```

不要依据设备型号、固定屏幕宽度或仅 `OrientationBuilder` 写两套独立页面。

## 4. 组件选型

| 需求 | 首选组件 | 说明 |
| --- | --- | --- |
| 带页头的二级页面 | `PixelPageScaffold` | 统一背景、Safe Area、阅读宽度、页头和正文约束 |
| 普通二级页列表 | `PixelPageList` | 统一横竖屏边距、底部留白与分组间距 |
| 二级页面顶部导航 | `PixelPageHeader` | 固定 71dp 高度、居中标题、左侧返回语义与键盘操作 |
| 带切角、轮廓和硬阴影的容器 | `PixelPanel` | 不手写 `Border`、`BoxShadow` 或切角路径 |
| 主要、次要、危险按钮 | `PixelButton` | 使用 `PixelButtonTone.primary/secondary/danger` |
| 轻量文字操作 | `PixelTextButton` | 无底板文字按钮，保留 48dp 点击区域、焦点与按压反馈 |
| 整行跳转或菜单操作 | `PixelActionTile` | 支持 leading、trailing、禁用、焦点、悬停与按压态 |
| 单选项 | `PixelSelectionTile` | 使用 `selected` 与 `onSelected`，不另画勾选框 |
| 开关项 | `PixelSwitch` | 提供 checked 语义、键盘 Enter/Space 交互和像素开关图形 |
| 设置分组 | `PixelSection` | 标题、阶梯外框和分隔线由组件管理 |
| 标签/值信息行 | `PixelInfoRow` | 统一元数据排版，不自行组合左右文字 |
| 带说明的链接行 | `PixelLinkTile` | 统一语义、键盘、悬停和按压反馈 |
| 紧凑文字清单 | `PixelTextList` | 用于面板内包列表、字体列表等只读清单 |
| 色彩选项 | `PixelColorOption` | 保留选中环和无障碍名称 |
| 工具栏 | `PixelToolbar` | 多个图标操作统一使用 |
| 底部弹层 | `PixelSheet.show` | 统一遮罩、焦点闭环、Esc 关闭、拖拽与安全区 |
| 单个图标 | `PixelIcon` | 仅使用已有 `PixelIconKind`；新增图标必须补齐像素绘制和测试 |
| 自定义可点击像素组件 | `PixelPressable` | 仅作为基础封装，业务页面优先使用上面的高级组件 |

## 5. 组合规范

### 5.1 设置页

```dart
PixelSection(
  title: 'Display',
  children: [
    PixelSwitch(label: 'Keep Screen Awake', value: value, onChanged: onChanged),
    PixelSwitch(label: 'Night Mode', value: nightMode, onChanged: onChanged),
  ],
)
```

- 设置分组的 `PixelSection.children` 只放同类型、同语义层级的设置项。
- 设置项之间不手动添加分隔线，`PixelSection` 会生成像素分隔线。
- 信息展示分组可设置 `showDividers: false`，组合 `PixelInfoRow`、`PixelLinkTile` 或 `PixelTextList`。
- 分组本身由页面的 `Wrap` 或网格负责横屏平铺，不把屏幕宽度判断塞进 `PixelSection`。

### 5.2 对话框与底部弹层

使用 `PixelSheet.show` 打开，而不是直接调用 `showModalBottomSheet`。它已处理：遮罩色、焦点恢复、Esc 键关闭、键盘焦点范围及 `disableAnimations`。

- Sheet 外框和内容裁切必须使用 `PixelThemeSheetFrame` 的阶梯切角；禁止使用 `ClipRRect`、`BorderRadius` 或连续圆角。
- Sheet 的大切角由 `PixelThemeSheetStyle.sheetCut` 和 `sheetPixel` 控制：每角使用 `7 × 6` 个像素格，横向步长为 `3-1-1-1-1`、纵向步长为 `1-1-1-1-2`，三层边框使用同一轮廓逐层内缩；不要在业务页面重画边框或切角。

### 5.3 工具栏

`PixelToolbar` 根据可用空间排列独立的 `PixelButton` 操作：紧凑竖屏使用全宽纵向按钮，其他布局使用自动换行的横向排列。横向工具栏不得额外包裹 `PixelPanel` 或任何背景、边框、阴影容器；仅保留每个操作按钮自身的像素边框与状态，避免按钮换行时形成整块背景框。

### 5.4 文字按钮

`PixelTextButton` 用于不应抢占页面视觉焦点的轻量操作，例如 Welcome 的 `SKIP`、`NEXT` 和 `GET STARTED`。它是文字按钮，不得再包裹 `PixelPanel`、Board 边框、大面积背景或硬阴影。

```dart
PixelTextButton(
  label: 'NEXT',
  prominent: true,
  onPressed: onNext,
)
```

- 标签使用简短英文大写；欢迎页固定为 `SKIP`、`NEXT`、`GET STARTED`。
- 次要操作使用默认文字色；主操作传入 `prominent: true` 使用 `tokens.accent`，但仍不绘制底板。
- 默认、禁用、悬停、按压和键盘焦点必须可区分；悬停/按压/焦点只显示透明叠层和底部像素线，不能退化为实心按钮。
- 组件已保证最小 `48dp` 高度与宽度；不要为视觉紧凑而缩小点击区域。
- 确认、危险、工具栏和需要明确边界的操作继续使用 `PixelButton`，不要以文字按钮替代。

### 5.5 自定义组件

确实没有现成组件时：

1. 用 `PixelTokens` 取色值、间距、描边与动效；
2. 可点击控件以 `PixelPressable` 为外层；
3. 外轮廓使用 `PixelPanel`、`PixelThemeOptionFrame` 或已有 `pixel_shape.dart` 路径；
4. 提供语义名称、enabled/selected/checked 状态；
5. 需要动效时通过 `tokens.motionDuration` 尊重“减少动态效果”系统设置；
6. 组件放入 `lib/core/ui/pixel/` 并从 `pixel_ui.dart` 导出，随后补充 widget 测试。

### 5.6 抽取边界与目录

- 只在单个 feature 使用、且携带明确业务语义的组合放在 `features/<feature>/widgets/`。
- 被两个页面复用，或统一了视觉、交互、语义、响应式行为的组件放在 `core/ui/pixel/`。
- 页面壳、分组、行、按钮等优先采用组合式 API；不要把业务状态、Provider 或路由读取放入公共组件。
- 业务页面统一 import `core/ui/ui.dart`。只有自定义 Painter、Shape 或组件内部实现可以直接 import `core/ui/pixel/*`。
- 表盘卡片尺寸、翻页轴件、数字光学偏移等属于 Clock 领域视觉，保留在 feature 内；通用页面组件不承载这些参数。
- 不因一段 Widget 较长就抽取；抽取应至少消除重复，或建立一项需要全项目一致的视觉/交互契约。

## 6. 交互与无障碍标准

- 点击目标最小尺寸为 `48 × 48dp`。
- 鼠标悬停、键盘焦点、按压、禁用状态必须可区分。
- Enter 与 Space 应能触发键盘可达的操作。
- 文本标签是交互控件的语义名称；图标按钮须明确指定语义名称。
- 不要嵌套多个可访问的 `Semantics` 按钮；需要自绘时使用 `ExcludeSemantics` 避免重复朗读。
- 测试至少覆盖：点击、禁用/选中状态、键盘或语义，以及 `2x` 字号下的内容可达性。

## 7. 验收清单

新增或改造页面提交前检查：

- [ ] 二级页面使用 `PixelPageScaffold`，没有重复的 `Scaffold + SafeArea + LayoutBuilder + PixelPageHeader`。
- [ ] 横屏无固定最大宽度，内容能利用完整 Safe Area。
- [ ] 横屏重复内容按 `contentWidth` 分栏，竖屏保持可滚动单列。
- [ ] 颜色、文字、间距、动效来自 `PixelTokens` 或既有组件。
- [ ] 可交互元素优先采用 Pixel 组件，而非 Material 默认按钮、开关或卡片。
- [ ] 轻量引导/导航操作使用 `PixelTextButton`；其标签、点击区域和状态反馈符合文字按钮规范。
- [ ] 有语义、键盘可达和减少动态效果支持。
- [ ] 补充 widget 测试；改变视觉基线时更新并验证 golden。
