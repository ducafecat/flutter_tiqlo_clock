# 标准组件样式规范

非像素风（`AppUiStyle.standard`）的唯一样式源。改视觉先改 Token / `Standard*` / 本文，再改页面。像素风走 `lib/core/ui/pixel/`，两套不能混用。

标准风：圆角、填充分层、Material 涟漪。像素风：切角、硬阴影、Pixel UI。页面只调 `App*`，由 `AppUiStyle` 切换实现。

## 0. 维护契约

改样式按这一层走，禁止在 feature 页另起一套色、间距、圆角、分隔线：

```
feature 页
  → App*（lib/core/ui/app/）
    → Standard*（lib/core/ui/standard/）
      → StandardColors / StandardSpacing / StandardRadius / StandardTextStyles
        → StandardTheme（写入 ThemeData）
```

| 要改什么 | 改哪里 |
| --- | --- |
| 页面/分组/描边/主色 | `StandardColors`，暗色页与 Sheet 必须共用 `clockSheet` / `sheetGroup` |
| 间距节奏 | `StandardSpacing`（8 / 12 / 16 / 24 / 32 / 40） |
| 圆角 | `StandardRadius` |
| 字号字重 | `StandardTextStyles` |
| Button / AppBar / Input / Chip / ListTile | `StandardTheme` |
| 分组、行、Panel、Sheet、Chrome | 对应 `Standard*` 组件 |
| Clock 表盘几何 | `lib/features/clock/widgets/faces/standard/` |
| Night Mode 变暗 | 只在 `ClockPage` 包 `ClockFace`，表盘内不读 `nightMode` |

新增可点击行：先加 `Standard*`，再在 `App*` 接适配器，页面只引用 `App*`。

允许写死色值的表面只有：Splash / Welcome 的品牌叠层、Clock 表盘配色、Session 品牌卡、Clock Chrome / Sheet 底板。常规 Settings / About / More / Theme 分组必须吃 Theme。

动效时长一律 `AppUiTheme.motionDuration`，系统「减少动态效果」时归零。

## 1. 使用入口

两套互不跟随的视觉：

1. **应用界面**：Settings、About、More、Theme Sheet。Material 3，`StandardTheme.darkTheme`。
2. **Clock 表面**：Flip / Digital 各自调色板。不是 Material Theme，也不等于 Night Mode。

```dart
import '../../../core/ui/ui.dart';
```

页面只用 `AppPageScaffold`、`AppSection`、`AppSwitch`、`AppSheetGroup` 等 `App*`。不要直接 import `standard/` 或 `pixel/`。

仅 Clock 页和表盘可直接用 `clock_theme.dart`、`flip_palette.dart`、`digital_theme.dart`。

## 2. 当前主题状态

`StandardTheme` 有 `lightTheme` 和 `darkTheme`。入口只挂暗色：

```dart
theme: StandardTheme.darkTheme,
```

Settings、About、Sheet **当前固定暗色**。亮色 Token 未上线，不要按亮色写已发布行为。

Night Mode ≠ Material Dark：表盘 `AnimatedOpacity` → `0.35`（240ms）、屏幕亮度尝试 `15%`、快照强制隐藏日期和秒。

## 3. 视觉 Token

### 3.1 颜色

常规页用 `Theme.of(context).colorScheme` 或 `StandardTextStyles.xxxOn(context)`，页内不判断 `Brightness`。

| 语义 | Theme 槽 | 亮色 | 暗色（现行） | 用途 |
| --- | --- | --- | --- | --- |
| 页面背景 | `scaffoldBackgroundColor` | `#F9F6EF` | `#1C1C1E` | Scaffold、Canvas、AppBar、Sheet 底板 |
| 主文字 | `bodyLarge` | `#4A3F2F` | `#FFFFFF` | 正文、开关标签 |
| 卡片背景 | `colorScheme.surface` | `#FFFFFF` | `#2E2E32` | 分组、Panel |
| 卡片主文字 | `colorScheme.onSurface` | `#1A1814` | `#FFFFFF` | 标题、选中态 |
| 主色 | `colorScheme.primary` | `#BF6A2E` | `#CA7835` | 主按钮、开关开 |
| 主色前景 | `colorScheme.onPrimary` | `#FFFFFF` | `#FFFFFF` | 主按钮字 |
| 弱背景 | `outlineVariant` / `secondary` | `#EBE5D0` | `#000000` | Chip 默认底 |
| 弱文字 | `onSurfaceVariant` | `#847E6A` | `#FFFFFFB3` | 辅助、图标、分区标题 |
| 危险 | `error` | `#D04B2B` | `#D04B2B` | 破坏性操作 |
| 危险前景 | `onError` | `#FFFFFF` | `#FFFFFF` | 危险按钮字 |
| 描边 | `outline` | `#D9D0B8` | `#FFFFFF1F` | 输入框、12% 白细线 |
| 分组细线 | `onSurface` 12% | — | `#FFFFFF1F` | 组内分隔 |

暗色页面与弹出层共用：

| Token | 色值 | 用途 |
| --- | --- | --- |
| `clockSheet` / `darkBackground` / `moreSheet` | `#1C1C1E` | 页底、More / Theme 底板 |
| `sheetGroup` / `darkCard` | `#2E2E32` | 分组填充 |
| `clockChrome` | `#E61C1C1E` | 底部 Chrome |

| `welcomeAccent` | `#E8B66B` | Welcome 页码选中点 |

`ColorScheme` 映射：`secondary` = muted，`surface` = card，`outline` = border。

次级文字用 `StandardTextStyles.secondaryOn` / `metaOn` / `onSurfaceVariant`，不用 `Colors.grey`，不用透明黑冒充分隔线。

### 3.2 字体

常规页平台默认字体，不指定 fontFamily。

| 语义 | Material 槽 | 字号 | 字重 | 行高 | 其他 |
| --- | --- | ---: | ---: | ---: | --- |
| `display` | `displaySmall` | 38 | 800 | 1.14 | |
| `pageTitle` | `headlineSmall` | 20 | 700 | 1.25 | AppBar |
| `sectionTitle` | `titleLarge` | 18 | 700 | 1.25 | |
| `body` | `bodyLarge` | 15 | 400 | 1.65 | 设置标签 |
| `secondary` | `bodyMedium` | 14 | 500 | 1.30 | 槽位默认仍是主文字色 |
| `meta` | `bodySmall` | 13 | 400 | 1.40 | 弱色 |

### 3.4 圆角

| Token | dp | 用途 |
| --- | ---: | --- |
| `sm` | 4 | 细节、Theme drag handle 高度 |
| `md` | 6 | 紧凑控件 |
| `lg` | 8 | 按钮、Chip、输入、配色按钮 |
| `xl` | 12 | 分组、Panel |
| `modal` | 28 | Sheet 顶角 |
| `pill` | 999 | 胶囊、页码点 |

复用 `card` / `control` / `modalBorderRadius` / `pillBorderRadius`。常规组件不新增 10、14、16。

### 3.5 阴影、描边与分组

分层靠 **surface 相对底板的填充差**，分组不描边、elevation 0。

| 元素 | 规则 |
| --- | --- |
| 分组 / Panel / Sheet 分组 | `surface` 填充，12dp 圆角，`Clip.hardEdge` |
| 组内分隔线 | 1dp、通栏、`onSurface` 12%；**叠在行底部**，不占高度 |
| 输入框等独立控件 | 1dp `outline` |
| 亮色阴影 | `#1A000000` |
| 暗色阴影 | `#26000000` |

分隔线用 `Stack` + `Positioned(bottom: 0)` + `IgnorePointer`。插入式 `Divider` 会在选中底和下一行之间露出 1dp 底板，左边一条断黑线。

`StandardTheme.dividerTheme` 给真正需要独立分割线的控件；分组内部不要用它。

## 4. Material 组件默认样式

业务页优先吃主题，不重复塞相同 `style`。

### 4.1 AppBar

- 背景 = 页面背景，前景 = `onSurface`
- `elevation` / `scrolledUnderElevation` = 0
- 标题 `20 / 700`
- 二级页用 `AppPageScaffold`，返回 `Icons.arrow_back`

### 4.2 ListTile

- 主题：字 `onSurface`，图标弱文字，`minTileHeight` 56
- Settings 开关、跳转行吃这套行高
- About 只读行 / 外链：`dense` + `compact`；`AppInfoRow` 另设 `minTileHeight` 44

### 4.3 Card

主题化 `Card` 带 1dp 描边，仅少量独立卡片。Settings / About / Sheet 分组和身份 Panel 用 `StandardSettingsGroup` / `StandardPanel`。

### 4.4 Chip

- 默认底弱背景、选中主色；字对应弱文字 / 主色前景
- 标签 `13 / 700`；水平 12、垂直 6；8dp 圆角、无边框
- Clock 配色不用 `ChoiceChip`，用 `AppColorOption`

### 4.5 按钮

| 组件 | 高度 | 水平垫 | 圆角 | 字 | 颜色 |
| --- | ---: | ---: | ---: | --- | --- |
| `ElevatedButton` | ≥40 | 16 | 8 | 14 / 700 | 主色底，elevation 0 |
| `FilledButton` | ≥40 | 16 | 8 | 14 / 700 | primary |
| `TextButton` | ≥40 | 16 | 8 | 14 / 500 | 主色字 |
| `IconButton` | ≥36×36 | 默认 | 8 | — | 弱文字 |

主操作：`ElevatedButton` / `FilledButton`。轻量：`TextButton`。危险：error 语义。Welcome 主按钮走 `AppTextButton(prominent: true)` → `FilledButton`，吃主题主色。

### 4.6 输入框

Card 填充；水平 16、垂直 12；默认 1dp outline；聚焦 2dp 主色；8dp 圆角；hint 15 弱色。

## 5. 共享组件

标准实现在 `lib/core/ui/standard/`。页面只碰 `App*`。

### 5.1 分组块

`StandardSettingsGroup` 是 Settings、About、More、Theme 的同一容器：

- `surface`、12dp、无描边、无 elevation
- `Clip.hardEdge` 裁切涟漪和选中底
- 相邻行叠 1dp 通栏 12% 细线
- 一组只放同层级项
- `Column(crossAxisAlignment: stretch)`

`StandardSection` = 大写分区标题 + 12dp + `StandardSettingsGroup`。

`AppSheetGroup` 标准风 = `StandardSettingsGroup`；像素风仍是逐项切角块。

密排列表（Credits）`showDividers: false`。配色网格：`showDividers: false` + 内边距 12，包一层分组。

### 5.2 分区标题

`StandardSectionHeader` / `StandardSheetSectionTitle`：标题 `toUpperCase()`，`labelOn`（11 / 800 / 字距 1.76），弱色。Sheet 标题额外水平/垂直 8dp 垫。

### 5.3 行组件

| App* | Standard* | 用途 | 要点 |
| --- | --- | --- | --- |
| `AppSwitch` | `StandardSwitch` | 布尔 | `SwitchListTile`，水平 16；More 传 `compact: true` |
| `AppActionTile` | `StandardActionTile` | 页内跳转 | 右侧 `chevron_right`，弱色 |
| `AppSelectionTile` | `StandardSelectionTile` | 单选行 | 选中底 `onSurface` 12%，右侧 check；选中底必须同层 `Material`，`ListTile.selectedTileColor` 透明。不能用 `ColoredBox` 铺底（会触发 ink 断言） |
| `AppColorOption` | `StandardColorOption` | 配色按钮 | 见下 |
| `AppInfoRow` | `StandardInfoRow` | 只读键值 | 标签左 `body`，值右 `secondaryOn` |
| `AppLinkTile` | `StandardLinkTile` | 外链 | 副标题 URL `metaOn`，右侧 `open_in_new` |
| `AppPanel` | `StandardPanel` | 自由内容块 | 与分组同填充圆角，默认垫 16 |
| `AppTextList` | `StandardTextList` | 字符串列表 | 垫 16，项间距 8，`secondaryOn` 左对齐 |
| — | `StandardSettingsTile` | 自定义行 | 水平 16、垂直 14 |

开关 → `AppSwitch`。跳转 → `AppActionTile`。外链 → `AppLinkTile`。

`AppColorOption`：

- 最小高 40；默认 `minWidth` 144，Theme 网格传 `0`
- 8dp 圆角；默认底 5% / 描边 12% 1dp；选中底 16% / 描边 55% 1.5dp
- 色点 18 圆，描边用第二色 1.5dp；选中打勾，亮底黑勾、暗底白勾
- 标签 `secondary` + `w600`，主文字色
- `colors[0]` 预览底，`colors[1]` 预览描边/数字

### 5.4 Sheet

`AppSheet.show` → `StandardSheet`。遮罩 `sheetBarrier`。局部 `Theme`：surface `#2E2E32`，字白，弱字 `white70`，outline 12% 白。

## 6. 页面组合

Settings、About、More、Theme 共用 5.1 分组。差别只有底板和有无 AppBar。

### 6.1 Settings

- `AppPageScaffold`，竖屏最大宽 426
- 竖屏水平 16、横屏 24；顶 24、底 32
- 分区标题与分组 12；分组之间 24
- 行 = `AppSwitch` + `AppSection`
- 横屏：`Wrap` 1～3 列，最小列宽 350（字号放大时加宽）

### 6.2 About

- `AppPageScaffold` + `AppPageList`，最大宽 720
- 竖屏水平 16、横屏 24；顶 16、底 24；块间距 16
- 身份 `AppPanel`：水平 16、垂直 12；名 `heading(22)`；`Version x.y.z (build)` 来自 `PackageInfo.fromPlatform()`，`body(13)` 弱色，间距 4
- `Links` 一组：Author `AppInfoRow` + 三个 `AppLinkTile`
- `Credits` 一组、`showDividers: false`：组内小标题 11 大写弱色 + `join('\n')` 13 弱色密排，块垫 16/12

### 6.3 Splash

品牌特例：全屏 `BoxFit.cover` 图，隐藏系统 UI，透明度 0→1，时长 `splashDuration` 900ms。不要把启动图规则套到 Settings。

### 6.4 Welcome

品牌沉浸页：

- 三图 `PageView` + `BoxFit.cover`
- 底渐变：透明 → 透明 → 90% 背景 → 背景，stops `0 / 0.5 / 0.76 / 1`
- SafeArea 最小垫：左 24、上 20、右 24、下 24
- 标题 `heading(30)`；说明 `body` + 弱色；文案切换 240ms
- 翻页 360ms `easeOutCubic`
- 页码：高 7，未选宽 7，选中宽 24，间距 7；选中 `welcomeAccent`，未选 `white30`
- SKIP = `AppTextButton`；NEXT / GET STARTED = `prominent` `FilledButton`

金色页码和渐变只留在 Welcome，不进 `StandardTheme` 通用按钮。

## 7. Clock 表面

### 7.1 通用布局

无 AppBar 全屏：

- Scaffold 背景 = 当前 Flip / Digital 背景
- 隐藏系统 UI
- 表盘内边距水平 24、垂直 32
- 横屏时内容区额外左右 `sm+xs`（20）；竖屏 0
- `FittedBox` 等比缩放，不裁切
- 横竖屏同一页、同一状态
- 点空白显隐 Chrome；显示后 3s 收起
- SafeArea：竖屏左右开、顶底关；横屏左右关

Night Mode（只在 `ClockPage`）：

- `AnimatedOpacity` 包 `ClockFace`，`key: clock-night-dim`
- 开：`opacity: 0.35`；关：`1`
- 时长 240ms（走 `motionDuration`）
- Chrome 不参与变暗
- 日期/秒由 `ClockSnapshot.showDate` / `showSeconds` 在 night 时为 false
- 亮度：`NightBrightness` → 应用亮度 0.15；失败吞掉（模拟器/桌面常无效）
- 表盘组件不读 `nightMode`，不自己加透明度

### 7.2 Digital

| | 竖屏 | 横屏 |
| --- | ---: | ---: |
| 字号 | 132 | 180 |
| 字体 | `DSEG7Classic` | 同左 |
| 字重 / 行高 | 700 / 1 | 同左 |

- 时分秒冒号连接，`digit` 色
- AM/PM：`24 / 900 / 字距 3`，距时间 6，`secondary` 色

- 语义：`snapshot.timeLabel`
- 无秒时光学校正：以 `1` 开头左移 `0.28×字号`，以 `1` 结尾右移；有秒不偏移

`#4D000000` = 30% 黑，`#40000000` = 25% 黑。标准风 Pure Dark 卡片色在 `StandardClockFace` 与表一致。

## 8. Clock 浮层

### 8.1 底部 Chrome

- 底对齐，底距 `sm+xs` = 20
- 无 Session：Theme、More、受支持平台 Fullscreen
- 运行中：Pause/Resume、Stop、可选 Fullscreen
- Complete：Done、可选 Fullscreen

瞬时操作层，不是常驻导航。Session 中不加无关按钮。

### 8.2 Theme Sheet

- `AppSheetLayout.theme`，可滚，有 handle
- 分区标题与 Settings 相同（大写 `label`）
- 标题到分组：`sm+xs` = 20；Clock Style 组到 Color 标题：24
- Clock Style：`AppSheetGroup` + `AppSelectionTile`
- Color Theme：同一分组、无细线、内垫 12，`Wrap` 间距 8
- `AppColorOption` 预览底/数字色

### 8.3 More Sheet

- 开关一组：Pixel UI、Night Mode（`compact`）
- 跳转一组：Settings、About
- 两组间距 16
- 关闭后重显 Chrome 并重启 3s 隐藏

## 9. 响应式与安全区

| 名称 | 宽 |
| --- | ---: |
| `smallPhone` | 360 |
| `phone` | 390 |
| `largePhone` | 430 |
| `tablet` | 600 |
| `desktop` | 1024 |

设计基准 `390 × 844`。`ScreenAdapt` 圆角/图标/字体缩放夹在 `0.95～1.12` / `0.95～1.10` / `0.98～1.08`。优先约束和断点，不要无差别缩放所有 dp。

- 阅读页：竖屏限宽居中（Settings 426、About 720），横屏铺满
- Clock：吃满可用区域
- 二级页 `AdaptivePageFrame` 自带 SafeArea
- 不按机型分支，不为横竖屏拆业务页
