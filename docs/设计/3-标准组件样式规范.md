# 标准组件样式规范

本文整理 `packages/flutter_tiqlo_clock_standard` 当前实现的视觉基础、Material 3 组件样式、共享组件、Clock 表面及页面组合规则。它既是现状说明，也是后续维护标准版界面时的样式约束。

> 本文只描述标准版子项目，不适用于根项目的像素风组件。标准版采用圆角、细描边和 Material 交互反馈；根项目采用切角、硬阴影和 Pixel UI，两者不能混用。

## 1. 设计定位与使用入口

标准版包含两套彼此独立的视觉系统：

1. **应用界面主题**：Settings、About 等常规页面使用 Material 3，由 `AppTheme`、`AppColors`、`AppTextStyles`、`AppSpacing` 和 `AppRadius` 统一管理。
2. **Clock 表面主题**：全屏 Clock 使用 `ClockThemeId` 选择 Flip 或 Digital，再由各自的调色板决定背景、数字和辅助信息颜色。它不是 Material Theme，也不跟随应用界面的亮暗主题。

常规 feature 页面统一导入：

```dart
import '../../../core/ui/ui.dart';
```

共享组件统一导入：

```dart
import '../../../shared/widgets/widgets.dart';
```

仅 Clock 页面和表盘组件可以直接使用 `clock_theme.dart`、`flip_palette.dart`、`digital_theme.dart` 中的领域视觉定义。

## 2. 当前主题状态

应用主题基于 Material 3：

```dart
ThemeData(
  useMaterial3: true,
  // ...
)
```

`AppTheme` 同时定义了 `lightTheme` 和 `darkTheme`，但当前 `MaterialApp.router` 只传入：

```dart
theme: AppTheme.darkTheme,
```

因此，**当前运行中的 Settings、About 等应用页面固定使用暗色主题**。亮色 Token 和 `AppTheme.lightTheme` 已准备好，但在应用入口接入主题切换之前，不应把亮色效果写成已上线行为。

Clock 的 Night Mode 也不是 Material 暗色模式。它只是一种显示策略：表盘透明度降为 `0.35`、应用屏幕亮度尝试降至 `15%`，并由 Clock 快照暂时隐藏日期和秒数。

## 3. 视觉 Token

### 3.1 颜色

所有常规页面优先使用 `Theme.of(context).colorScheme` 或 `AppColorsX` 的语义 getter，不在页面中重复判断 `Brightness`。

| 语义 | BuildContext API | 亮色 | 暗色 | 用途 |
| --- | --- | --- | --- | --- |
| 页面背景 | `context.appBackground` | `#F9F6EF` | `#2D2A24` | `Scaffold`、Canvas 背景 |
| 主文字 | `context.appForeground` | `#4A3F2F` | `#CCC3A8` | 正文 |
| 卡片背景 | `context.appCard` | `#FFFFFF` | `#373330` | Card、设置分组、AppBar |
| 卡片主文字 | `context.appCardFg` | `#1A1814` | `#F9F6EF` | 标题和高层级内容 |
| 主色 | `context.appPrimary` | `#BF6A2E` | `#CA7835` | 主操作、焦点描边 |
| 主色前景 | `context.appPrimaryFg` | `#FFFFFF` | `#FFFFFF` | 主按钮文字 |
| 弱背景 | `context.appMuted` | `#EBE5D0` | `#222019` | Chip、弱强调区域 |
| 弱文字 | `context.appMutedFg` | `#847E6A` | `#BFB89E` | 辅助信息、标签、图标 |
| 危险色 | `context.appDestructive` | `#D04B2B` | `#D04B2B` | 错误或破坏性操作 |
| 危险色前景 | `context.appDestructiveFg` | `#FFFFFF` | `#FFFFFF` | 危险操作文字 |
| 描边 | `context.appBorder` | `#D9D0B8` | `#474038` | 卡片、输入框、分隔线 |

Material `ColorScheme` 的主要映射如下：

| ColorScheme 槽位 | 标准版语义 |
| --- | --- |
| `primary / onPrimary` | 主色 / 主色前景 |
| `secondary / onSecondary` | 弱背景 / 弱文字 |
| `surface / onSurface` | 卡片背景 / 卡片主文字 |
| `error / onError` | 危险色 / 危险色前景 |
| `outline` | 描边 |
| `outlineVariant`、`surfaceContainerHighest` | 弱背景 |
| `onSurfaceVariant` | 弱文字 |

不要用 `Colors.grey` 模拟弱文字，也不要用透明黑色替代通用描边。Clock、启动页和欢迎页属于沉浸式特例，其颜色可由各自的视觉定义管理。

### 3.2 字体层级

常规页面不指定自定义字体族，使用平台默认字体。文字样式通过 `AppTextStyles` 或映射后的 `ThemeData.textTheme` 获取。

| 语义样式 | Material 槽位 | 字号 | 字重 | 行高 | 其他 |
| --- | --- | ---: | ---: | ---: | --- |
| `display` | `displaySmall` | 38 | 800 | 1.14 | 大型展示文字 |
| `pageTitle` | `headlineSmall` | 20 | 700 | 1.25 | 页面标题、AppBar 标题 |
| `sectionTitle` | `titleLarge` | 18 | 700 | 1.25 | 内容区标题 |
| `body` | `bodyLarge` | 15 | 400 | 1.65 | 正文与设置项标签 |
| `secondary` | `bodyMedium` | 14 | 500 | 1.30 | 次级正文 |
| `meta` | `bodySmall` | 13 | 400 | 1.40 | 元信息 |
| `label` | `labelSmall` | 11 | 800 | 1.20 | 字距 `1.76`，分区标题 |
| `caption` | 无固定映射 | 12 | 400 | 1.30 | 小型说明 |

`AppTextStyles.secondaryOn(context)` 使用弱文字色；Material `bodyMedium` 只复用相同的字号、字重和行高，默认仍使用主文字色。需要表达“次级信息”时应显式使用前者，不能只靠 `bodyMedium` 推断颜色语义。

推荐用法：

```dart
Text('Settings', style: AppTextStyles.pageTitleOn(context));
Text('Description', style: AppTextStyles.bodyOn(context));
Text('Metadata', style: AppTextStyles.metaOn(context));
```

`xxxOn(context)` 只补充与当前主题对应的颜色，不改变字号、字重和行高。

表盘字体是领域特例：

| 表盘 | 字体族 | 字体文件 | 字重 |
| --- | --- | --- | ---: |
| Flip | `FlipClock` | `RobotoCondensed-Bold.ttf` | 700 |
| Digital | `DSEG7Classic` | `DSEG7Classic-Bold.ttf` | 700 |

### 3.3 间距

常规页面采用以下基础节奏：

| Token | 尺寸 |
| --- | ---: |
| `AppSpacing.xs` | 8dp |
| `AppSpacing.sm` | 12dp |
| `AppSpacing.md` | 16dp |
| `AppSpacing.lg` | 24dp |
| `AppSpacing.xl` | 32dp |
| `AppSpacing.xxl` | 40dp |

页面布局优先从该序列取值。只有表盘光学校正、动画结构或沉浸式欢迎页确有视觉需要时，才允许使用独立尺寸。

### 3.4 圆角

| Token | 尺寸 | 典型用途 |
| --- | ---: | --- |
| `AppRadius.sm` | 4dp | 小型细节 |
| `AppRadius.md` | 6dp | 紧凑控件 |
| `AppRadius.lg` | 8dp | 按钮、Chip、输入框、图标按钮 |
| `AppRadius.xl` | 12dp | Card、设置分组 |
| `AppRadius.modal` | 28dp | Modal |
| `AppRadius.pill` | 999dp | 胶囊形控件 |

可直接复用 `cardBorderRadius`、`modalBorderRadius`、`chipBorderRadius` 和 `pillBorderRadius`。常规组件不要随意新增 10、14、16 等圆角；Clock Theme Sheet、Welcome 和表盘卡片属于当前已存在的页面级特例。

### 3.5 阴影与描边

- 常规 Card：`0dp` elevation，`1dp` 语义描边。
- `SettingsGroup`：`1dp` elevation、`#14000000` 阴影、`1dp` 语义描边。
- 亮色全局阴影色：`#1A000000`；暗色全局阴影色：`#26000000`。
- Divider：`1dp` 厚度、`1dp` 占位，颜色使用语义描边。
- 标准版强调轻描边和柔和层次，不使用像素风硬阴影与阶梯切角。

## 4. Material 组件默认样式

`AppTheme` 已统一以下 Material 组件。业务页面优先直接使用主题化组件，不重复传入相同 `style`。

### 4.1 AppBar

- 背景使用 Card 色，前景使用 Card 主文字色；
- `elevation` 和 `scrolledUnderElevation` 均为 `0`；
- 标题为 `20dp / 700`；
- 普通二级页面使用 `Scaffold + AppBar`，由 Flutter 自动提供返回按钮。

### 4.2 Card

- 背景使用 Card 色；
- 无外边距、无 elevation；
- `12dp` 圆角；
- `1dp` 语义描边。

### 4.3 Chip

- 默认背景使用弱背景，选中背景使用主色；
- 默认文字使用弱文字色，选中文字使用主色前景；
- 标签为 `13dp / 700`；
- 水平内边距 `12dp`、垂直内边距 `6dp`；
- `8dp` 圆角、无边框；
- 全局默认隐藏 checkmark。Clock Theme Sheet 为沉浸式特例，会显式覆盖选中样式和 checkmark。

### 4.4 按钮

| 组件 | 高度 | 水平内边距 | 圆角 | 文字 | 颜色 |
| --- | ---: | ---: | ---: | --- | --- |
| `ElevatedButton` | 最小 40dp | 16dp | 8dp | `14dp / 700` | 主色底、主色前景，无 elevation |
| `TextButton` | 最小 40dp | 16dp | 8dp | `14dp / 500` | 主色文字、透明背景 |
| `IconButton` | 最小 `36 × 36dp` | 组件默认 | 8dp | — | 弱文字色 |

常规主操作优先使用已统一主题的 `ElevatedButton`；轻量导航和次要操作使用 `TextButton`；纯图标操作使用 `IconButton`。`FilledButton` 当前没有项目级组件主题，只用于 Welcome 等显式声明完整局部样式的场景。危险操作必须明确使用危险语义色。

### 4.5 输入框

- Card 色填充；
- 水平内边距 `16dp`、垂直内边距 `12dp`；
- 默认和启用态为 `1dp` 语义描边；
- 聚焦态为 `2dp` 主色描边；
- `8dp` 圆角；
- hint 为 `15dp` 弱文字色。

## 5. 共享组件

### 5.1 `SectionHeader`

用于 Settings 等常规页面的分组标题：

- 标题自动转为大写；
- 使用 `AppTextStyles.labelOn(context)`；
- 占满剩余水平空间；
- 可通过 `trailing` 放置右侧操作。

```dart
const SectionHeader(title: 'Time & Date');
```

不要在页面中重复拼装“大写标题 + 11dp 粗体 + 字距”的样式。

### 5.2 `SettingsTile`

用于自定义设置行：

- 结构为 `leading / label / trailing`；
- 水平内边距 `16dp`、垂直内边距 `14dp`；
- leading 与正文间距 `12dp`；
- 正文使用 `AppTextStyles.bodyOn(context)`；
- 通过 `InkWell` 提供 Material 点击反馈。

如果需求只是布尔开关，优先使用 `SwitchListTile`；需要自定义 leading、值展示或跳转行为时使用 `SettingsTile`。

### 5.3 `SettingsGroup`

用于组合语义相关的设置项：

- Card 色背景、`12dp` 圆角、`1dp` 描边；
- `1dp` elevation 和轻阴影；
- 使用 `Clip.hardEdge` 限制涟漪；
- 自动在相邻 children 之间插入 Divider，调用方不再手动添加。

```dart
SettingsGroup(
  children: [
    SwitchListTile(
      title: const Text('Night Mode'),
      value: value,
      onChanged: onChanged,
    ),
  ],
)
```

一个 `SettingsGroup` 只组合相同主题、相同信息层级的设置项。

## 6. 页面组合规范

### 6.1 Settings

Settings 是常规二级页面的主要参考实现：

- 使用主题化 `Scaffold` 和 `AppBar`；
- 正文必须可垂直滚动；
- 页面四周为 `16dp` 内边距；
- 内容水平居中，最大宽度 `720dp`；
- 分区标题与分组间距 `12dp`；
- 分组之间间距 `24dp`；
- 设置行优先使用 `SwitchListTile` 或 `SettingsTile`；
- 分组统一使用 `SettingsGroup`。

常规信息页可沿用相同的 `720dp` 阅读宽度。About 当前仅为最小实现：居中显示版本号，不应被视为完整内容页模板。

### 6.2 启动页

Splash 是品牌视觉特例：

- 纯黑背景、图片全屏 `BoxFit.cover`；
- 隐藏系统 UI；
- 图片从 `0.88` 缩放至 `1.0`，同时淡入；
- 动画时长 `900ms`，曲线 `easeOutCubic`；
- 启动页总停留时间约 `1100ms`。

不要把 Splash 的黑色背景或全屏图片规则复用到常规页面。

### 6.3 Welcome

Welcome 同样属于独立的品牌沉浸式页面：

- 黑色背景，三张全屏图片通过 `PageView` 横向切换；
- 图片使用 `BoxFit.cover`；
- 底部叠加由透明到黑色的渐变，stops 为 `0 / 0.5 / 0.76 / 1`；
- Safe Area 最小内边距为左 `24dp`、上 `12dp`、右 `24dp`、下 `20dp`；
- 标题为白色、`800` 字重、行高 `1.18`；说明文字为 `white70`、行高 `1.55`；
- 文案切换使用 `240ms` 的 `AnimatedSwitcher`；翻页使用 `360ms easeOutCubic`；
- 页码点高 `7dp`，未选中宽 `7dp`，选中宽 `24dp`，间距 `7dp`；
- 主按钮最小 `132 × 50dp`，金色 `#E8B66B` 背景、黑色文字、`16dp` 圆角；
- “跳过”使用白色 70% 文字与 `#33000000` 半透明底。

这些金色、渐变和大圆角是 Welcome 的局部品牌样式，不加入通用 `AppTheme`。

## 7. Clock 表面规范

### 7.1 通用布局

Clock 是无 AppBar 的沉浸式全屏表面：

- 背景色直接来自当前 Flip Palette 或 Digital Theme；
- 隐藏系统 UI；
- 表盘外边距为水平 `24dp`、垂直 `32dp`；
- 内容通过 `FittedBox` 在可用空间内等比缩放，不能出现裁切；
- 横竖屏只是同一个 Clock 的布局变化，不创建第二套页面；
- 点击空白区域显示或隐藏底部 Chrome；Chrome 显示后 `3s` 自动收起。

Night Mode 激活时，表盘整体透明度为 `0.35`。日期与秒是否显示由 `ClockSnapshot` 决定，表盘组件不要自行读取设置状态。

### 7.2 Digital Clock

| 项目 | 竖屏 | 横屏 |
| --- | ---: | ---: |
| 基准字号 | 132dp | 180dp |
| 字体 | `DSEG7Classic` | `DSEG7Classic` |
| 字重 | 700 | 700 |
| 行高 | 1 | 1 |

- 时、分以及可选秒用冒号连接；
- 时间使用当前 Digital Theme 的 `digit` 色；
- 12 小时制的 AM/PM 使用 `24dp / 900 / 3dp 字距`，与时间间距 `6dp`；
- 日期使用 `18dp / 2dp 字距`，与上方内容间距 `16dp`；
- AM/PM 和日期使用 `secondary` 色；
- 整个时间区域提供 `snapshot.timeLabel` 语义标签。

不显示秒时需要保留数字“1”的光学校正：时间以 `1` 开头时向左移动 `0.28 × 字号`，以 `1` 结尾时向右移动相同距离；两项可相互抵消。显示秒时不应用该偏移。

### 7.3 Flip Clock

| 项目 | 竖屏 | 横屏 |
| --- | ---: | ---: |
| 卡片高度 | 210dp | 260dp |
| 卡片宽度 | 高度 × 1.08 | 高度 × 1.08 |
| 卡片排列 | 垂直 | 水平 |
| 卡片间距 | 高度 × 0.09 | 高度 × 0.09 |
| 日期字号 | 16dp | 22dp |

- 每个时间段使用一张独立卡片；默认显示时和分，开启秒后增加第三张；
- 12 小时制的 AM/PM badge 位于小时卡左上方；
- 卡片圆角为卡宽的 `8.5%`；
- 数字字号为卡高的 `82%`，字重 `700`、行高 `0.94`、负字距为卡高的 `1.2%`；
- 上半卡、下半卡和中线颜色由 `FlipPalette` 提供；
- 日期颜色为数字色的 `55%` 透明度，字重 `400`、字距 `1.5dp`，与卡片间距 `20dp`；
- 卡片保留柔和黑色投影与 `0.8dp` 半透明黑色外描边；
- 翻页动画为 `1000ms`，使用余弦缓动、X 轴旋转和 `0.0028` 透视参数。

卡片尺寸、阴影比例、3D 透视与数字光学校正属于 Clock 领域视觉，只保留在 `features/clock/widgets/`，不要抽入通用 Material Token。

### 7.4 Session 表面

Focus 或 Timer 运行时临时替换墙上时间，但延续当前 ClockTheme 的颜色语义：

| 当前 ClockTheme | 竖屏时间字号 | 横屏时间字号 | 主色 | 辅助色 |
| --- | ---: | ---: | --- | --- |
| Digital | 88dp | 136dp | `digitalTheme.digit` | `digitalTheme.secondary` |
| Flip | 72dp | 120dp | `flipPalette.digit` | 数字色 70% 透明度 |

- 运行或暂停时显示 `mm:ss`；Complete 时显示 `COMPLETE`；
- 主显示字重 `300`、字距 `2dp`；
- Session 类型为 `18dp / 2dp 字距`；
- Complete 时额外显示 `18dp` 的分钟数；
- 各信息块间距为 `16dp`。

## 8. Clock 浮层与操作 Chrome

### 8.1 底部 Chrome

- 位于底部居中，底部间距为 `12dp + iOS safe bottom`；
- 背景 `#E61C1C1E`；
- `16dp` elevation，黑色阴影；
- Stadium 胶囊外形，边框为 12% 白色；
- 内边距为水平 `6dp`、垂直 `2dp`；
- 操作使用白色 `16dp` TextButton；
- 无 Session 时显示 Theme、More，以及受支持平台上的 Fullscreen；
- Session 运行时只显示 Pause/Resume、Stop 和可选 Fullscreen；
- Complete 时只显示 Done 和可选 Fullscreen。

Chrome 是 Clock 的瞬时操作层，不要替换成常驻导航栏，也不要在 Session 运行中追加与 Session 无关的操作。

### 8.2 Theme Sheet

- 使用 `showModalBottomSheet`，允许内容滚动并显示 drag handle；
- 背景为 `#1C1C1E`；
- 内容包裹 Safe Area 和 `SingleChildScrollView`；
- 内容内边距为左 `16dp`、右 `16dp`、下 `24dp`；
- 分区标题为 `white70 / 13dp / 700 / 1.2dp 字距`，水平和垂直内边距均为 `8dp`；
- Clock Style 使用 `ListTile`，圆角 `14dp`；选中背景为 8% 白色，并显示白色 check；
- Color Theme 使用可换行的 `ChoiceChip`，横向和纵向间距均为 `8dp`；
- Chip 通过圆形 avatar 同时预览背景/卡片色和数字色；
- Chip 默认背景为 6% 白色，选中背景为 16% 白色；默认描边为 12% 白色，选中描边为 70% 白色。

### 8.3 More Sheet

- 背景使用 `Colors.grey.shade900`（约 `#212121`）；
- 内容包裹 Safe Area；
- Night Mode 使用 `SwitchListTile`；
- Settings 和 About 使用 `ListTile`；
- 所有标题使用白色；
- Sheet 关闭后重新显示底部 Chrome，并重启 `3s` 自动隐藏计时。

## 9. 响应式与安全区

### 9.1 断点

项目定义了以下统一断点：

| 名称 | 宽度 |
| --- | ---: |
| `smallPhone` | 360dp |
| `phone` | 390dp |
| `largePhone` | 430dp |
| `tablet` | 600dp |
| `desktop` | 1024dp |

`ScreenAdapt` 以 `390 × 844dp` 为设计基准，并提供宽高缩放；圆角、图标和字体分别限制在 `0.95～1.12`、`0.95～1.10`、`0.98～1.08` 范围内。

当前页面主要依赖弹性布局、`FittedBox`、最大宽度和横竖屏判断，`AdaptiveBreakpoints` 与 `ScreenAdapt` 尚未被 feature 页面实际调用。后续接入时遵循以下原则：

- 优先使用约束、弹性布局和断点，不要把所有尺寸无差别缩放；
- 常规阅读页面设置合理最大宽度并水平居中；
- 全屏 Clock 使用完整可用空间；
- 使用 `SafeArea` 或 `safeTop / safeBottom / safeLeft / safeRight` 处理刘海和手势区域；
- 不按设备型号分支，不为横竖屏创建不同业务页面。

## 11. 开发约束与验收清单

- [ ] 常规页面通过 `core/ui/ui.dart` 获取颜色、文字、间距和圆角。
- [ ] 没有在业务页面重复声明已有的语义色和文字层级。
- [ ] Card、Button、Chip、Input、AppBar 优先使用 `AppTheme` 的全局默认值。
- [ ] Settings 类页面保持滚动、`16dp` 页面边距和 `720dp` 最大阅读宽度。
- [ ] 设置分组使用 `SectionHeader + SettingsGroup`，分隔线由分组生成。
- [ ] ClockTheme 与 Material Theme 保持独立，Night Mode 不命名为 Dark Mode。
- [ ] Clock 横竖屏共享相同状态和页面，只调整排列与基准尺寸。
- [ ] 沉浸式页面的硬编码颜色仅限 Splash、Welcome、Clock 和 Clock Sheet，不扩散到常规页面。
- [ ] 新增可点击组件具备清晰的启用、按压、选中或禁用状态，并使用 Material 反馈。
- [ ] 文本放大、窄屏、横屏和 Safe Area 下内容仍可访问，无溢出或裁切。
- [ ] 样式变更同步补充 widget 测试；改变表盘视觉基线时更新并验证 golden。
