# 标准组件样式规范

本文整理根项目 `lib/core/ui/standard/` 当前实现的视觉基础、Material 3 组件样式、共享组件、Clock 表面及页面组合规则。它既是现状说明，也是后续维护标准版界面时的样式约束。

标准版采用圆角、填充分层和 Material 交互反馈；像素风采用切角、硬阴影和 Pixel UI。两者不能混用。标准版实现放在 `lib/core/ui/standard/`，像素风放在 `lib/core/ui/pixel/`，页面通过 `App*` 适配器按 `AppUiStyle` 切换。

## 1. 设计定位与使用入口

标准版包含两套彼此独立的视觉系统：

1. **应用界面主题**：Settings、About 等常规页面使用 Material 3，由 `StandardTheme`、`StandardColors`、`StandardTextStyles`、`StandardSpacing` 和 `StandardRadius` 统一管理。
2. **Clock 表面主题**：全屏 Clock 使用 `ClockThemeId` 选择 Flip 或 Digital，再由各自的调色板决定背景、数字和辅助信息颜色。它不是 Material Theme，也不跟随应用界面的亮暗主题。

常规 feature 页面统一导入：

```dart
import '../../../core/ui/ui.dart';
```

页面只使用 `AppPageScaffold`、`AppSection`、`AppSwitch`、`AppSheetGroup` 等 `App*` 适配器，不要直接引用 Pixel / Standard 实现。

仅 Clock 页面和表盘组件可以直接使用 `clock_theme.dart`、`flip_palette.dart`、`digital_theme.dart` 中的领域视觉定义。

## 2. 当前主题状态

应用主题基于 Material 3。`StandardTheme` 同时定义了 `lightTheme` 和 `darkTheme`，但当前 `MaterialApp.router` 在标准风下只传入：

```dart
theme: StandardTheme.darkTheme,
```

因此，**当前运行中的 Settings、About 等应用页面固定使用暗色主题**。亮色 Token 已准备好，但在应用入口接入主题切换之前，不应把亮色效果写成已上线行为。

Clock 的 Night Mode 也不是 Material 暗色模式。它只是一种显示策略：表盘透明度降为 `0.35`、应用屏幕亮度尝试降至 `15%`，并由 Clock 快照暂时隐藏日期和秒数。

## 3. 视觉 Token

### 3.1 颜色

所有常规页面优先使用 `Theme.of(context).colorScheme` 或 `StandardTextStyles.xxxOn(context)`，不在页面中重复判断 `Brightness`。

| 语义 | 取值 | 亮色 | 暗色 | 用途 |
| --- | --- | --- | --- | --- |
| 页面背景 | `Theme.scaffoldBackgroundColor` | `#F9F6EF` | `#1C1C1E` | `Scaffold`、Canvas、AppBar、Sheet 底板 |
| 主文字 | `colorScheme` 映射后的 `bodyLarge` | `#4A3F2F` | `#FFFFFF` | 正文 |
| 卡片背景 | `colorScheme.surface` | `#FFFFFF` | `#2E2E32` | 设置分组、Sheet 分组 |
| 卡片主文字 | `colorScheme.onSurface` | `#1A1814` | `#FFFFFF` | 标题和高层级内容 |
| 主色 | `colorScheme.primary` | `#BF6A2E` | `#CA7835` | 主操作、开关开启态 |
| 主色前景 | `colorScheme.onPrimary` | `#FFFFFF` | `#FFFFFF` | 主按钮文字 |
| 弱背景 | `colorScheme.outlineVariant` | `#EBE5D0` | `#000000` | Chip、弱强调区域 |
| 弱文字 | `colorScheme.onSurfaceVariant` | `#847E6A` | `#FFFFFFB3` | 辅助信息、标签、图标 |
| 危险色 | `colorScheme.error` | `#D04B2B` | `#D04B2B` | 错误或破坏性操作 |
| 危险色前景 | `colorScheme.onError` | `#FFFFFF` | `#FFFFFF` | 危险操作文字 |
| 描边 | `colorScheme.outline` | `#D9D0B8` | `#FFFFFF1F` | 输入框、12% 白细线 |
| 分组细线 | `onSurface` 12% 透明 | — | `#FFFFFF1F` | 分组内部分隔线 |

暗色页面、More Sheet、Theme Sheet 共用这套表面色：

| Token | 色值 | 用途 |
| --- | --- | --- |
| `StandardColors.clockSheet` / `darkBackground` / `moreSheet` | `#1C1C1E` | 页面与 Sheet 底板 |
| `StandardColors.sheetGroup` / `darkCard` | `#2E2E32` | 分组填充 |
| `StandardColors.clockChrome` | `#E61C1C1E` | 底部 Chrome |

不要用 `Colors.grey` 模拟弱文字，也不要用透明黑色替代通用描边。Clock、启动页和欢迎页属于沉浸式特例，其颜色可由各自的视觉定义管理。

### 3.2 字体层级

常规页面不指定自定义字体族，使用平台默认字体。文字样式通过 `StandardTextStyles` 或映射后的 `ThemeData.textTheme` 获取。

| 语义样式 | Material 槽位 | 字号 | 字重 | 行高 | 其他 |
| --- | --- | ---: | ---: | ---: | --- |
| `display` | `displaySmall` | 38 | 800 | 1.14 | 大型展示文字 |
| `pageTitle` | `headlineSmall` | 20 | 700 | 1.25 | 页面标题、AppBar 标题 |
| `sectionTitle` | `titleLarge` | 18 | 700 | 1.25 | 内容区标题 |
| `body` | `bodyLarge` | 15 | 400 | 1.65 | 正文与设置项标签 |
| `secondary` | `bodyMedium` | 14 | 500 | 1.30 | 次级正文 |
| `meta` | `bodySmall` | 13 | 400 | 1.40 | 元信息 |
| `label` | `labelSmall` | 11 | 800 | 1.20 | 字距 `1.76`，分区标题 |
| `caption` | 无固定映射 | 12 | 400 | 1.30 | 小型说明 |

`StandardTextStyles.secondaryOn(context)` 使用弱文字色；Material `bodyMedium` 只复用相同的字号、字重和行高，默认仍使用主文字色。需要表达“次级信息”时应显式使用前者。

```dart
Text('Settings', style: StandardTextStyles.pageTitleOn(context));
Text('Description', style: StandardTextStyles.bodyOn(context));
Text('Metadata', style: StandardTextStyles.metaOn(context));
```

`xxxOn(context)` 只补充与当前主题对应的颜色，不改变字号、字重和行高。

表盘字体是领域特例：

| 表盘 | 字体族 | 字体文件 | 字重 |
| --- | --- | --- | ---: |
| 标准 Flip | `FlipClock` | `RobotoCondensed-Bold.ttf` | 700 |
| 标准 Digital | `DSEG7Classic` | `DSEG7Classic-Bold.ttf` | 700 |

### 3.3 间距

常规页面采用以下基础节奏：

| Token | 尺寸 |
| --- | ---: |
| `StandardSpacing.xs` | 8dp |
| `StandardSpacing.sm` | 12dp |
| `StandardSpacing.md` | 16dp |
| `StandardSpacing.lg` | 24dp |
| `StandardSpacing.xl` | 32dp |
| `StandardSpacing.xxl` | 40dp |

页面布局优先从该序列取值。只有表盘光学校正、动画结构或沉浸式欢迎页确有视觉需要时，才允许使用独立尺寸。

### 3.4 圆角

| Token | 尺寸 | 典型用途 |
| --- | ---: | --- |
| `StandardRadius.sm` | 4dp | 小型细节 |
| `StandardRadius.md` | 6dp | 紧凑控件 |
| `StandardRadius.lg` | 8dp | 按钮、Chip、输入框、图标按钮 |
| `StandardRadius.xl` | 12dp | 分组、Panel |
| `StandardRadius.modal` | 28dp | Sheet 顶部圆角 |
| `StandardRadius.pill` | 999dp | 胶囊形控件 |

可直接复用 `StandardRadius.card`、`modalBorderRadius`、`control` 和 `pillBorderRadius`。常规组件不要随意新增 10、14、16 等圆角。

### 3.5 阴影、描边与分组

标准版用**填充色差**分层，不用描边框住分组。

| 元素 | 规则 |
| --- | --- |
| 页面分组 / Panel / Sheet 分组 | `colorScheme.surface` 填充，`12dp` 圆角，`0` elevation，无描边 |
| 分组相对页面 / Sheet 底板 | 仅靠 surface 与背景的亮度差分层 |
| 分组内部分隔线 | `1dp` 高、通栏、`onSurface` 12% 透明；叠在行底部，不占布局高度 |
| 输入框等独立控件 | 仍使用 `1dp` 语义描边 |
| 亮色全局阴影色 | `#1A000000` |
| 暗色全局阴影色 | `#26000000` |

不要用 `Divider` 插入行与行之间。插入式 Divider 会在选中底和下一行之间留下 1dp 空隙，左缘会露出底板色，看起来像断掉的黑线。

## 4. Material 组件默认样式

`StandardTheme` 已统一以下 Material 组件。业务页面优先直接使用主题化组件，不重复传入相同 `style`。

### 4.1 AppBar

- 背景使用页面背景色，前景使用 Card 主文字色；
- `elevation` 和 `scrolledUnderElevation` 均为 `0`；
- 标题为 `20dp / 700`；
- 普通二级页面使用 `AppPageScaffold`，由适配器提供返回按钮。

### 4.2 Card

主题化 `Card` 仍带 `1dp` 语义描边，供少量独立卡片使用。Settings、About、Sheet 的分组和身份 Panel **不要用 Card**，统一走 `StandardSettingsGroup` / `StandardPanel`（无描边填充块）。

### 4.3 Chip

- 默认背景使用弱背景，选中背景使用主色；
- 默认文字使用弱文字色，选中文字使用主色前景；
- 标签为 `13dp / 700`；
- 水平内边距 `12dp`、垂直内边距 `6dp`；
- `8dp` 圆角、无边框。

Clock Theme Sheet 的配色选项不使用 `ChoiceChip`，而使用 `AppColorOption`。

### 4.4 按钮

| 组件 | 高度 | 水平内边距 | 圆角 | 文字 | 颜色 |
| --- | ---: | ---: | ---: | --- | --- |
| `ElevatedButton` | 最小 40dp | 16dp | 8dp | `14dp / 700` | 主色底、主色前景，无 elevation |
| `FilledButton` | 最小 40dp | 16dp | 8dp | `14dp / 700` | 主题 primary |
| `TextButton` | 最小 40dp | 16dp | 8dp | `14dp / 500` | 主色文字、透明背景 |
| `IconButton` | 最小 `36 × 36dp` | 组件默认 | 8dp | — | 弱文字色 |

常规主操作优先使用已统一主题的 `ElevatedButton` 或 `FilledButton`；轻量导航和次要操作使用 `TextButton`。危险操作必须明确使用危险语义色。

### 4.5 输入框

- Card 色填充；
- 水平内边距 `16dp`、垂直内边距 `12dp`；
- 默认和启用态为 `1dp` 语义描边；
- 聚焦态为 `2dp` 主色描边；
- `8dp` 圆角；
- hint 为 `15dp` 弱文字色。

## 5. 共享组件

feature 页面通过 `App*` 适配器使用这些组件。标准风实现位于 `lib/core/ui/standard/`。

### 5.1 分组块

`StandardSettingsGroup` 是 Settings、About、More、Theme Sheet 的同一套分组容器：

- `colorScheme.surface` 填充；
- `12dp` 圆角、无描边、无 elevation；
- `Clip.hardEdge` 裁切涟漪和选中底；
- 相邻行之间叠 `1dp`、通栏、`onSurface` 12% 的细线，不占用垂直空间；
- 一个分组只放相同主题、相同信息层级的项。

`StandardSection` = 大写分区标题 + `12dp` 间距 + `StandardSettingsGroup`。

`AppSheetGroup` 在标准风下就是 `StandardSettingsGroup`；像素风保持原有逐项切角块，不套这层卡片。

```dart
AppSection(
  title: 'Time & Date',
  children: [
    AppSwitch(label: '24 Hour', value: value, onChanged: onChanged),
  ],
)
```

### 5.2 分区标题

`StandardSectionHeader` / `StandardSheetSectionTitle`：

- 标题自动转为大写；
- 使用 `StandardTextStyles.labelOn(context)`（`11dp / 800 / 1.76 字距`）；
- 弱文字色。

不要在页面中重复拼装“大写标题 + 11dp 粗体 + 字距”。

### 5.3 行组件

| 组件 | 用途 | 标准风要点 |
| --- | --- | --- |
| `AppSwitch` | 布尔开关 | `SwitchListTile`，水平内边距 `16dp` |
| `AppActionTile` | 页内跳转 | 右侧 `chevron_right` |
| `AppSelectionTile` | 单选一行 | 选中底为 `onSurface` 12%，右侧 check；选中底用同层 `Material` 铺满 |
| `AppColorOption` | 配色按钮 | `8dp` 圆角按钮；默认底 5% / 描边 12%；选中底 16% / 描边 55%、1.5dp |
| `AppInfoRow` | 只读键值 | 标签左、值右 |
| `AppLinkTile` | 外链 | 副标题为 URL，右侧 `open_in_new` |
| `StandardSettingsTile` | 自定义行 | 水平 `16dp`、垂直 `14dp` |

开关用 `AppSwitch`；跳转用 `AppActionTile`；外链用 `AppLinkTile`。

### 5.4 Panel

`StandardPanel` 与分组块同一套填充和圆角，只是内部是自由内容而不是行列表。About 顶部身份区使用它，不要改回带描边的 `Card`。

## 6. 页面组合规范

Settings、About、More Sheet、Theme Sheet 共用第 5.1 节的分组块。区别只在底板色和是否有 AppBar。

### 6.1 Settings

- 使用 `AppPageScaffold`；
- 正文必须可垂直滚动；
- 竖屏水平内边距 `16dp`，横屏 `24dp`；
- 内容水平居中，最大宽度 `426dp`；
- 分区标题与分组间距 `12dp`；
- 分组之间间距 `24dp`；
- 设置行使用 `AppSwitch`；
- 分组使用 `AppSection`。

### 6.2 About

- 使用 `AppPageScaffold` 与 `AppPageList`；
- 竖屏水平内边距 `16dp`，横屏 `24dp`，分组间距 `16dp`；
- 内容水平居中，最大宽度 `720dp`；
- 顶部身份区用紧凑 `AppPanel`：应用名 + `Version x.y.z (build)`，值来自 `PackageInfo.fromPlatform()`；
- 链接合并为一组 `Links`；致谢合并为一组 `Credits`（Packages / Fonts 为组内小标题 + 密排文本）。

### 6.3 启动页

Splash 是品牌视觉特例：

- 纯黑背景、图片全屏 `BoxFit.cover`；
- 隐藏系统 UI；
- 图片从 `0.88` 缩放至 `1.0`，同时淡入；
- 动画时长 `900ms`，曲线 `easeOutCubic`；
- 启动页总停留时间约 `1100ms`。

不要把 Splash 的黑色背景或全屏图片规则复用到常规页面。

### 6.4 Welcome

Welcome 同样属于独立的品牌沉浸式页面：

- 黑色背景，三张全屏图片通过 `PageView` 横向切换；
- 图片使用 `BoxFit.cover`；
- 底部叠加由透明到黑色的渐变，stops 为 `0 / 0.5 / 0.76 / 1`；
- Safe Area 最小内边距为左 `24dp`、上 `12dp`、右 `24dp`、下 `20dp`；
- 标题为白色、`800` 字重、行高 `1.18`；说明文字为 `white70`、行高 `1.55`；
- 文案切换使用 `240ms` 的 `AnimatedSwitcher`；翻页使用 `360ms easeOutCubic`；
- 页码点高 `7dp`，未选中宽 `7dp`，选中宽 `24dp`，间距 `7dp`；
- 主按钮最小 `132 × 50dp`，金色 `#E8B66B` 背景、黑色文字、`16dp` 圆角；
- “跳过”使用白色 70% 文字与 `#33000000` 半透明底。

这些金色、渐变和大圆角是 Welcome 的局部品牌样式，不加入通用 `StandardTheme`。

## 7. Clock 表面规范

### 7.1 通用布局

Clock 是无 AppBar 的沉浸式全屏表面：

- 背景色直接来自当前 Flip Palette 或 Digital Theme；
- 隐藏系统 UI；
- 表盘外边距为水平 `24dp`、垂直 `32dp`；
- 内容通过 `FittedBox` 在可用空间内等比缩放，不能出现裁切；
- 横竖屏只是同一个 Clock 的布局变化，不创建第二套页面；
- 点击空白区域显示或隐藏底部 Chrome；Chrome 显示后 `3s` 自动收起。

Night Mode 激活时，表盘整体透明度为 `0.35`。日期与秒是否显示由 `ClockSnapshot` 决定，表盘组件不要自行读取设置状态。

### 7.2 Digital Clock

| 项目 | 竖屏 | 横屏 |
| --- | ---: | ---: |
| 基准字号 | 132dp | 180dp |
| 字体 | `DSEG7Classic` | `DSEG7Classic` |
| 字重 | 700 | 700 |
| 行高 | 1 | 1 |

- 时、分以及可选秒用冒号连接；
- 时间使用当前 Digital Theme 的 `digit` 色；
- 12 小时制的 AM/PM 使用 `24dp / 900 / 3dp 字距`，与时间间距 `6dp`；
- 日期使用 `18dp / 2dp 字距`，与上方内容间距 `16dp`；
- AM/PM 和日期使用 `secondary` 色；
- 整个时间区域提供 `snapshot.timeLabel` 语义标签。

不显示秒时需要保留数字“1”的光学校正：时间以 `1` 开头时向左移动 `0.28 × 字号`，以 `1` 结尾时向右移动相同距离；两项可相互抵消。显示秒时不应用该偏移。

### 7.3 Flip Clock

| 项目 | 竖屏 | 横屏 |
| --- | ---: | ---: |
| 卡片高度 | 210dp | 260dp |
| 卡片宽度 | 高度 × 1.08 | 高度 × 1.08 |
| 卡片排列 | 垂直 | 水平 |
| 卡片间距 | 高度 × 0.09 | 高度 × 0.09 |
| 日期字号 | 16dp | 22dp |

- 每个时间段使用一张独立卡片；默认显示时和分，开启秒后增加第三张；
- 12 小时制的 AM/PM badge 位于小时卡左上方；
- 卡片圆角为卡宽的 `8.5%`；
- 数字字号为卡高的 `82%`，字重 `700`、行高 `0.94`、负字距为卡高的 `1.2%`；
- 上半卡、下半卡和中线颜色由 `FlipPalette` 提供；
- 日期颜色为数字色的 `55%` 透明度，字重 `400`、字距 `1.5dp`，与卡片间距 `20dp`；
- 卡片保留柔和黑色投影与 `0.8dp` 半透明黑色外描边；
- 翻页动画为 `1000ms`，使用余弦缓动、X 轴旋转和 `0.0028` 透视参数。

卡片尺寸、阴影比例、3D 透视与数字光学校正属于 Clock 领域视觉，只保留在 `lib/features/clock/widgets/`，不要抽入通用 Material Token。

### 7.4 Session 表面

Focus 或 Timer 运行时临时替换墙上时间，但延续当前 ClockTheme 的颜色语义：

| 当前 ClockTheme | 竖屏时间字号 | 横屏时间字号 | 主色 | 辅助色 |
| --- | ---: | ---: | ---: | --- |
| Digital | 88dp | 136dp | `digitalTheme.digit` | `digitalTheme.secondary` |
| Flip | 72dp | 120dp | `flipPalette.digit` | 数字色 70% 透明度 |

- 运行或暂停时显示 `mm:ss`；Complete 时显示 `COMPLETE`；
- 主显示字重 `300`、字距 `2dp`；
- Session 类型为 `18dp / 2dp 字距`；
- Complete 时额外显示 `18dp` 的分钟数；
- 各信息块间距为 `16dp`。

## 8. Clock 浮层与操作 Chrome

### 8.1 底部 Chrome

- 位于底部居中，底部间距为 `12dp + iOS safe bottom`；
- 背景 `#E61C1C1E`；
- `16dp` elevation，黑色阴影；
- Stadium 胶囊外形，边框为 12% 白色；
- 内边距为水平 `6dp`、垂直 `2dp`；
- 操作使用白色 `16dp` TextButton；
- 无 Session 时显示 Theme、More，以及受支持平台上的 Fullscreen；
- Session 运行时只显示 Pause/Resume、Stop 和可选 Fullscreen；
- Complete 时只显示 Done 和可选 Fullscreen。

Chrome 是 Clock 的瞬时操作层，不要替换成常驻导航栏，也不要在 Session 运行中追加与 Session 无关的操作。

### 8.2 Theme Sheet

- 通过 `AppSheet` 弹出，允许内容滚动；Theme 布局显示 drag handle；
- 底板 `#1C1C1E`，分组填充 `#2E2E32`；
- 内容内边距为左 `16dp`、右 `16dp`、下 `24dp`；
- 分区标题与 Settings 相同：大写 `label` 样式；
- Clock Style 放进 `AppSheetGroup`，行使用 `AppSelectionTile`；
- Color Theme 的按钮网格放进同一个分组块，内边距 `12dp`；
- `AppColorOption` 用色点预览背景/数字色；选中为 16% 白底、55% 白描边。

### 8.3 More Sheet

- 底板 `#1C1C1E`，分组规则与 Theme Sheet、Settings、About 相同；
- 开关一组：Pixel UI、Night Mode；
- 跳转一组：Settings、About，右侧 chevron；
- 两组之间间距 `16dp`；
- Sheet 关闭后重新显示底部 Chrome，并重启 `3s` 自动隐藏计时。

## 9. 响应式与安全区

### 9.1 断点

项目定义了以下统一断点：

| 名称 | 宽度 |
| --- | ---: |
| `smallPhone` | 360dp |
| `phone` | 390dp |
| `largePhone` | 430dp |
| `tablet` | 600dp |
| `desktop` | 1024dp |

`ScreenAdapt` 以 `390 × 844dp` 为设计基准，并提供宽高缩放；圆角、图标和字体分别限制在 `0.95～1.12`、`0.95～1.10`、`0.98～1.08` 范围内。

当前页面主要依赖弹性布局、`FittedBox`、最大宽度和横竖屏判断。后续接入时遵循以下原则：

- 优先使用约束、弹性布局和断点，不要把所有尺寸无差别缩放；
- 常规阅读页面设置合理最大宽度并水平居中；
- 全屏 Clock 使用完整可用空间；
- 使用 `SafeArea` 或 `safeTop / safeBottom / safeLeft / safeRight` 处理刘海和手势区域；
- 不按设备型号分支，不为横竖屏创建不同业务页面。

## 11. 开发约束与验收清单

- [ ] 常规页面通过 `core/ui/ui.dart` 获取 `App*` 适配器，不直接引用 Pixel / Standard 实现。
- [ ] 没有在业务页面重复声明已有的语义色和文字层级。
- [ ] Settings、About、More、Theme 的分组都走 `StandardSettingsGroup` 规则：填充分层、无描边、通栏 12% 细线。
- [ ] 分组细线叠在行上，不使用插入式 `Divider`。
- [ ] Card、Button、Chip、Input、AppBar 优先使用 `StandardTheme` 的全局默认值。
- [ ] Settings / About 保持滚动、`16dp` 竖屏边距和文档中的最大阅读宽度。
- [ ] ClockTheme 与 Material Theme 保持独立，Night Mode 不命名为 Dark Mode。
- [ ] Clock 横竖屏共享相同状态和页面，只调整排列与基准尺寸。
- [ ] 沉浸式页面的硬编码颜色仅限 Splash、Welcome、Clock 和 Clock Sheet，不扩散到常规页面。
- [ ] 新增可点击组件具备清晰的启用、按压、选中或禁用状态，并使用 Material 反馈。
- [ ] 文本放大、窄屏、横屏和 Safe Area 下内容仍可访问，无溢出或裁切。
- [ ] 样式变更同步补充 widget 测试；改变表盘视觉基线时更新并验证 golden。
