# Tiqlo 像素风实施方案

> 文档状态：已确认，作为 Flutter UI 改造与验收基线。
>
> 设计方向：**Minimal Pixel UI（现代极简布局 + 像素字体 + 像素几何）**。
>
> 产品基线：覆盖当前项目全部运行时界面，但不新增产品功能；现有 ADR、产品行为、路由和持久化契约优先于视觉方案。

## 1. 目标

将 Tiqlo 的全部运行时界面统一为克制、清晰的像素视觉语言，同时保留桌面时钟应有的易读性、沉浸感和跨尺寸适配能力。

本方案要达到以下结果：

- Clock 始终是视觉中心，像素风不能削弱时间的远距离可读性。
- Theme 和 Settings 使用同一套颜色、字体、切角、描边、阴影和交互状态。
- Splash、Welcome、More、About 与既有 Session 状态使用同一套 Pixel UI；现有 Splash / Welcome 插画保持不变。
- 设计稿作为风格与结构基准，不按截图像素尺寸硬编码。
- 继续使用 Flutter 动态 Widget 实现主题、时间和翻页动画，不把页面或数字卡片图片化。
- 保持现有状态模型、路由、持久化键和业务行为不变。

## 2. 设计稿索引

### 2.1 Flip 主时钟

![Flip 主时钟](./1-flip.png)

设计稿表达的关键特征：

- 纯黑背景，画面中心只有上下堆叠的小时与分钟卡片。
- 卡片使用暖黑渐变、细描边、阶梯切角和克制的暗色阴影。
- 数字为高对比米白色像素字；12 小时制时，AM/PM 放在小时卡左上角。
- 卡片中轴是明确的水平黑线，两侧轴件提供机械翻页感。
- 竖屏按小时、分钟纵向排列；秒数开启时增加同规格卡片。

### 2.2 Theme 底部面板

![Theme 底部面板](./2-theme.png)

设计稿表达的关键特征：

- 打开面板后保留上方时钟预览，选择结果即时反映到预览。
- 面板从底部覆盖页面，顶部使用阶梯切角和短拖拽指示条。
- Clock Style 使用整行选择项；选中项有高亮描边和像素勾选标记。
- Color Theme 使用紧凑的自适应网格；色样图标、文字、边框共同表达状态，不能只依赖颜色。
- 面板内容可滚动，不能因小屏、横屏或系统文字缩放而溢出。

### 2.3 Settings 页面

![Settings 页面](./3-setting.png)

设计稿表达的关键特征：

- 固定深色 chrome，顶部保留平台安全区、返回入口和居中标题。
- 设置项按 Time & Date、Display、Alerts 分为三个语义组。
- 分组标题使用低饱和暖金色，内容容器使用暖灰黑底、细描边和阶梯切角。
- 开关关闭时为暗灰，开启时使用橙色轨道与米白色滑块。
- 每行整体均可点击，行高需满足触控和文字缩放要求。

## 3. 视觉系统

### 3.1 颜色

颜色以语义 token 管理，不在页面和控件中散落硬编码值。下表是实施基线；最终值可在真机对照设计稿后微调，但语义关系不得改变。

| Token | 建议基线 | 用途 |
| --- | --- | --- |
| `pixelBackground` | `#000000` | Clock 主背景、Pure Dark 背景 |
| `pixelChrome` | `#171612` | Theme 面板、Settings 页面背景 |
| `pixelSurface` | `#26231F` | 设置分组和普通选择项 |
| `pixelSurfaceHigh` | `#302C27` | 选中项、悬停态、卡片高光层 |
| `pixelTextPrimary` | `#F4F0E6` | 时间、标题、主要标签 |
| `pixelTextSecondary` | `#AAA59B` | 次要信息、未选中标签 |
| `pixelOutline` | `#5B554B` | 卡片和分组描边、分隔线 |
| `pixelAccent` | `#E87512` | 开启状态和主要激活态 |
| `pixelSection` | `#B8A77C` | Settings 分组标题、拖拽指示条 |
| `pixelShadow` | `#000000` | 硬边阴影和层级分离 |
| `pixelFocus` | 真机校准 | 与选中态不同的键盘焦点外框 |
| `pixelDanger` | 真机校准 | Stop 等破坏性操作 |
| `pixelDisabledSurface` | 真机校准 | 禁用控件表面 |
| `pixelDisabledText` | 真机校准 | 禁用控件文字 |
| `pixelBarrier` | 真机校准 | 模态面板遮罩 |
| `pixelHoverOverlay` | 真机校准 | hover 反馈层 |
| `pixelPressedOverlay` | 真机校准 | pressed 反馈层 |

规则：

- 主要文字与背景的对比度至少达到 WCAG AA；大号时间也应优先达到 4.5:1。
- 激活状态不能只通过颜色区分，必须同时使用勾选、描边、位置或文字状态。
- 设计稿中的柔和光晕只用于弱化背景和建立层次；控件轮廓、文字和像素图标必须保持硬边。
- Flip 与 Digital 各自已有的主题色仍由现有主题模型管理；Pixel UI token 负责页面 chrome 和通用控件，不覆盖时钟主题语义。

### 3.2 字体

字体方案锁定为 **Jersey 25 + Pixelify Sans + Tiny5**，并保留 Digital 专用的 **DSEG7Classic**。各字体按内容角色严格分工，不在同一控件中混用多种字体。

| 排版角色 | Flutter 字体族 | 使用范围 | 字重 |
| --- | --- | --- | --- |
| Flip Display | `Jersey25` | Flip 主数字 | `400` |
| Digital Display | `DSEG7Classic` | Digital 主数字 | `700` |
| Heading | `PixelifySans` | 页面标题、分组标题 | `600` |
| Body / Label | `PixelifySans` | 按钮、设置项、菜单和短正文 | `400` |
| HUD | `Tiny5` | AM/PM、FOCUS、TIMER、PAUSED 等短状态标签 | `400` |
| 中文 | System fallback | Welcome 文案及所有中文 | 跟随平台 |

对应的设计 token：

| Token | 字体族 | 用途 |
| --- | --- | --- |
| `pixelFlipDisplay` | `Jersey25` | Flip 数字 |
| `pixelDigitalDisplay` | `DSEG7Classic` | Digital 数字 |
| `pixelHeading` | `PixelifySans` | 页面和分组标题 |
| `pixelBody` | `PixelifySans` | 按钮、设置项、菜单和短正文 |
| `pixelHud` | `Tiny5` | AM/PM 与短状态标签 |
| `systemFallback` | 平台系统字体 | 中文、缺失字符和必要的可读性回退 |

约束：

- Jersey 25 只承担 Flip Display；数字按参考图做高窄比例校准。
- Pixelify Sans 承担标题和短 UI 文案；长段落和中文正文优先使用系统字体回退。
- Digital 数字继续使用现有 `DSEG7Classic`，维持七段数码管风格。
- Tiny5 只用于简短 HUD，不用于说明文字、主题名称或通用 Caption；建议字号不低于 `14 sp`，并单独验证小字号辨识度。
- Pixelify Sans 支持 `400–700` 可变字重；Heading 使用 `FontWeight.w600`，Body / Label 使用 `FontWeight.w400`。
- 官方来源：[Jersey 25](https://github.com/google/fonts/tree/main/ofl/jersey25)、[Pixelify Sans](https://github.com/eifetx/Pixelify-Sans)、[Tiny5](https://github.com/Gissio/font_Tiny5)。
- 字体文件固定版本后随仓库分发，不依赖运行时网络下载；只纳入实际使用的字重。
- `0–9` 在 Flip 卡片内应保持稳定宽度和基线；不同数字切换时不能引起卡片布局抖动。
- 小字号下检查 `1/I`、`0/O`、`5/S` 的辨识度，尤其验证 Tiny5 HUD，不能为追求像素感牺牲状态可读性。
- 中文不使用三款像素字体强行替代，也不通过低分辨率栅格化伪造像素效果。
- 字体渲染不主动降低分辨率。像素感来自字体轮廓和几何结构，而不是模糊或马赛克效果。

#### 字体授权与分发

三款新增字体均采用 **SIL Open Font License 1.1（OFL-1.1）**，允许嵌入商业 Flutter App、游戏和其他软件，也允许随软件一起分发，因此可用于 Tiqlo 的 App Store 与 Google Play 商业版本。

| 字体 | License | 商业使用 | Flutter App 内嵌 |
| --- | --- | --- | --- |
| Jersey 25 | SIL Open Font License 1.1 | ✅ | ✅ |
| Pixelify Sans | SIL Open Font License 1.1 | ✅ | ✅ |
| Tiny5 | SIL Open Font License 1.1 | ✅ | ✅ |

分发约束：

- 不得把字体文件本身作为独立商品出售。
- 随 App 重新分发字体时必须一并保留对应的 `OFL.txt`、版权声明和许可证信息。
- 如修改字体文件，需要遵守 OFL 对衍生字体和 Reserved Font Name 的要求；本项目默认使用未经修改的官方构建。
- 应记录每个字体文件的上游仓库、文件名、版本或 commit 和获取日期，避免后续无法复现 golden。
- 应用商店上架许可来自字体授权；最终发布仍需遵守 Apple、Google 及目标地区的其他审核与合规要求。

项目沿用现有根级 `fonts/` 目录，建议结构如下：

```text
fonts/
├── Jersey25-Regular.ttf
├── PixelifySans-Regular.ttf
├── PixelifySans-SemiBold.ttf
├── Tiny5-Regular.ttf
└── licenses/
    ├── Jersey25-OFL.txt
    ├── PixelifySans-OFL.txt
    └── Tiny5-OFL.txt
```

若最终采用 Pixelify Sans 可变字体文件，应固定该文件版本，并在 Flutter 字体配置和排版测试中分别验证 `w400` 与 `w600` 的实际渲染结果；不要同时提交未使用的静态与可变版本。

### 3.3 像素几何

- 不使用普通连续圆角模拟像素切角。通用容器使用阶梯式 Path 或 ShapeBorder。
- 基础像素单位为 `4 dp`；切角、描边偏移和硬阴影尽量对齐该网格。
- 通用组件切角使用小控件 `8 dp`、中型容器 `12 dp`、大面板 `16 dp`；Flip 卡片在 768px 参考画布使用 `40 px` 四级阶梯切角并随整体等比缩放。
- 描边默认 `1–2 dp`；统一绘制实现根据 DPR 对齐物理像素，页面不自行处理半像素偏移。
- 阴影使用短距离、低模糊或零模糊的硬边阴影。大面积环境暗化可以柔和，但不能污染控件边缘。
- 像素 PNG 使用整数倍缩放并设置 `FilterQuality.none`；优先使用代码绘制或适合硬边渲染的矢量资源。

### 3.4 间距与触控

- 页面水平安全间距：手机窄屏至少 `16 dp`，常规手机建议 `20–24 dp`。
- 基础间距序列：`4 / 8 / 12 / 16 / 24 / 32 dp`。
- 可交互区域最小为 `48 × 48 dp`；像素图标本身可以更小，但必须置于合格的点击区域内。
- Settings 行默认不低于 `64 dp`；文字放大后允许行高增长，不截断文本。
- 使用 SafeArea 处理刘海、Dynamic Island、桌面窗口边界和系统手势区，不复刻设计稿中的系统状态栏。

### 3.5 动效

- Flip 翻页使用 `600 ms`；PixelSwitch 使用 `150 ms`；按压和焦点反馈使用 `100 ms`。
- Welcome 按钮翻页使用 `300 ms`，文案与分页器状态使用 `150 ms`。
- Flutter Splash 只做 `300 ms` 淡入，不再缩放。
- 系统关闭动画时，Flip 直接替换数字，Splash 直接显示，Welcome 直接跳页，控件状态立即更新。
- 不新增弹跳、视差、像素抖动或仅为装饰存在的连续动画。

## 4. 页面规范

### 4.1 Flip 主时钟

#### 布局

- 时钟内容在可用区域内水平、垂直居中。
- 竖屏时小时、分钟、可选秒数纵向排列；横屏时改为横向排列。
- 所有卡片保持同一宽高比和视觉重量，通过约束和 `FittedBox` 适配，不为不同方向复制页面。
- 开启 Date & Weekday 时，日期位于卡片组下方并使用次要文字色；Night Mode 开启后继续按现有行为隐藏日期和秒数。
- 12 小时制在小时卡左上角使用 Tiny5 显示 AM/PM；24 小时制不保留空占位。

#### 卡片外观

- 上下半卡使用略有差异的暖黑色或同色渐变，中心分割线始终清晰。
- 外轮廓使用阶梯切角、暗色描边和短硬阴影。
- 中轴两侧绘制对称轴件；轴件属于装饰层，不参与布局和点击。
- 数字应充分占据卡片但保留安全边距，切换数值时不能发生横向跳动。
- Pure Dark 主题以黑背景、近黑卡片和米白数字为基准；全部十组 Flip 配色继续使用现有 `FlipPaletteId`。

#### 翻页动画

- 保留当前上下半层裁剪与 3D `rotateX` 实现，不使用 Lottie 或逐帧 PNG。
- 数值变化时，上半旧值向下翻至 90°，随后下半新值从 90°展开；静止层必须在两个阶段正确衔接。
- 动画期间保持中心轴、卡片外框和布局稳定，避免整张卡片重排。
- 动画固定为 `600 ms`，并以真机可读性与连续秒数模式的稳定性为验收条件。
- 系统启用“减少动态效果”时直接替换数字，不播放 3D 翻转或淡入。

### 4.2 Digital 主时钟

- 保留现有 `DSEG7Classic`、九组 `DigitalThemeId` 配色和无卡片的极简时间表面。
- 不把 Digital 包装成 Flip 式卡片；统一日期、AM/PM、Session、Clock chrome 和交互入口的 Pixel UI 语言。
- Digital 配色只影响 Clock 表面，不改变固定深色 Pixel chrome。

### 4.3 Theme 底部面板

#### 结构

```text
Clock 实时预览
└─ Pixel Theme Sheet
   ├─ Drag Handle
   ├─ Clock Style
   │  ├─ Flip
   │  └─ Digital
   └─ Color Theme
      └─ 当前样式对应的配色网格
```

- 沿用从 Clock 工具栏打开 Theme 的现有流程。
- 面板打开时，顶部保留足够的 Clock 可视区域；小屏或横屏可减少预览高度，但不能让选择内容不可达。
- 面板高度受可用空间约束，内部内容独立滚动。
- Compact 竖屏最大高度为可用高度的 `78%`，Compact 横屏可提高到 `92%`；Medium / Expanded 最大宽度 `720 dp`、最大高度 `80%`。
- 选择 Clock Style 后立即切换预览，并展示该样式自己的配色；Flip 和 Digital 的配色选择相互独立保留。
- 选择配色后即时生效并通过现有存储自动保存，不增加确认按钮。
- 移动端支持拖拽关闭；点击遮罩、系统返回键和 Escape 均可关闭，关闭时不回滚选择。
- 模态打开后焦点留在面板内，关闭后返回触发按钮。

#### Clock Style 选择项

- 使用自定义像素选择行替代默认 `ListTile` 外观。
- 选中项同时显示高亮描边、较高表面色和像素勾选；未选中项保留可感知边界。
- 整行可点击，键盘焦点、鼠标悬停、按下和禁用状态均有清晰反馈。

#### Color Theme 网格

- Flip 展示现有十组：Pure Dark、Dark、Light、Green、Blue、Red、Orange、Yellow、Purple、Pink。
- Digital 展示现有九组，并按 Flip 的颜色顺序排列：Pure Dark、Dark、Light、Digital（Green）、Digital-Blue、Digital-Red、Digital-Orange、Digital-Amber（Yellow）、Classic。
- 网格以 `144 dp` 为选项最小宽度，根据可用宽度自动换列，不固定复刻截图的三列结构。
- 每项包含色样、名称和选中状态。色样使用像素环或方形切角色块，不使用平滑圆形作为主要视觉。
- Light、Yellow 等浅色主题的选中标记必须保持足够对比度。

### 4.4 Settings 页面

#### 信息结构

设置项和语义保持当前 MVP 不变：

| 分组 | 设置项 | 初始状态 |
| --- | --- | --- |
| Time & Date | 24 Hour | 关闭（12 小时制） |
| Time & Date | Show Leading Zero | 关闭 |
| Time & Date | Show Seconds | 关闭 |
| Time & Date | Date & Weekday | 关闭 |
| Display | Keep Screen Awake | 开启 |
| Display | Night Mode | 关闭 |
| Alerts | Sound | 开启 |
| Alerts | Vibration | 开启 |

> 默认值以当前 `ClockEngine` 和设置存储实现为最终依据；文档不创建新的偏好项或存储键。

#### 页面与分组

- AppBar 使用固定深色背景、像素标题和像素化返回图标；返回行为保持平台导航语义。
- 页面垂直滚动，底部保留 SafeArea 间距。
- 页面正文最大宽度为 `720 dp`。
- 分组标题使用大写英文和暖金色，但仍向语义树暴露原始可读标签。
- 分组容器使用阶梯切角和细描边；内部行通过清晰分隔线分开。
- 点击行标签或开关均切换对应设置，点击区域不能只覆盖开关本体。

#### Pixel Switch

- 关闭：暗色轨道、灰色滑块、弱描边。
- 开启：橙色轨道、米白滑块、较亮描边。
- 滑块按像素网格平移，外形使用阶梯切角，不使用 Material 默认胶囊圆角。
- 状态变化使用 `150 ms` 短促位移动画；关闭动画时立即更新视觉与语义状态。
- 支持点击、键盘切换、焦点态和屏幕阅读器的 on/off 描述。

### 4.5 Clock chrome 与 Session

- Clock 空闲 chrome 保留 Theme、More 和受支持平台上的 Fullscreen / Exit Fullscreen；继续在显示三秒后自动隐藏。
- 操作使用文字优先的 PixelButton，不强制添加装饰图标。
- Session 继续继承当前 ClockTheme palette，不引入固定咖啡主题或新的状态模型。
- Running 显示 `mm:ss` 与 `FOCUS` / `TIMER`；Paused 额外显示 `PAUSED`；Complete 显示 `COMPLETE` 与既有时长信息。
- 操作严格保持 Pause / Resume / Stop / Done；不增加进度条、Summary、Break 或插画流程。

### 4.6 More 底部面板

- More 保持独立 PixelSheet，内容只有 Night Mode、Settings 和 About。
- Night Mode 使用 PixelSwitch；Settings 与 About 使用 PixelActionTile。
- 面板按内容自适应高度，同时受 SafeArea 和可用高度限制；关闭与焦点行为和 Theme PixelSheet 一致。

### 4.7 Splash 与 Welcome

- 保留现有一张 Splash 和三张 Welcome 插画，不重新生成或像素化位图内容。
- Splash 只统一背景和 reduced-motion 行为；Welcome 统一文字、按钮、分页器、间距和交互状态。
- 保留 Welcome 的三页结构、中文文案、左右滑动、跳过、下一步和开始使用行为。
- 中文继续使用系统字体回退，不强行使用 Pixelify Sans。

### 4.8 About

- 使用与 Settings 一致的固定深色页面 chrome、Pixel 返回图形和最大 `720 dp` 正文宽度。
- 只显示现有版本信息，不新增许可、隐私、反馈或品牌内容。

## 5. Pixel UI 模块 seam

Pixel UI 是一个深模块：页面只通过小而语义化的公开接口获得完整几何、状态、输入与无障碍行为。业务状态继续留在现有 Clock 模块中。

| 公开模块 | 职责 | 不负责 |
| --- | --- | --- |
| `PixelTheme` / `PixelTokens` | 通过 `ThemeExtension` 提供颜色、字体、间距、描边和动效 token | Clock 配色业务选择 |
| `PixelPanel` | 统一表面、描边、切角、阴影和裁剪 | 设置状态读写 |
| `PixelButton` | 统一主要、次要和危险操作及完整交互状态 | 执行业务动作 |
| `PixelActionTile` | 展示导航或即时动作 | 表达选中状态 |
| `PixelSelectionTile` | 展示文本、选中标记及完整交互状态 | 保存主题偏好 |
| `PixelColorOption` | 展示主题色样、名称和选中态 | 定义主题列表 |
| `PixelSwitch` | 展示并操作布尔值，提供语义和键盘交互 | 持久化布尔值 |
| `PixelSection` | 组合分组标题、容器、行和分隔线 | 决定设置项内容 |
| `PixelToolbar` | 排列 Clock 的文字操作并处理尺寸约束 | 决定 Session 操作集合 |
| `PixelSheet` | 统一模态、拖拽、滚动、焦点和关闭行为 | 决定面板内容 |
| `PixelPageIndicator` | 表达 Welcome 页码和状态变化 | 控制 PageView |
| `PixelIcon` | 提供 back、check 等最小像素图形集合 | 为每个文字按钮增加装饰 |

模块规则：

- 页面通过参数传入语义状态和回调，不直接把 Riverpod provider 或 SharedPreferences 放入 Pixel UI 模块。
- 阶梯 Path / ShapeBorder、DPR 对齐、硬阴影、交互状态绘制和 reduced-motion 判断是内部实现，不进入公开接口。
- 语义标签、焦点顺序和键盘操作由模块接口覆盖，不能仅依赖视觉层。
- `FlipCard` 留在 Clock feature 内，使用 Pixel UI token，但不成为通用模块。
- `ClockEngine`、`ClockSnapshot`、`ClockThemeId`、`FlipPaletteId` 和 `DigitalThemeId` 的职责及持久化方式保持不变。
- Pixel UI 是应用 chrome 的设计系统；Clock 自身的 Flip/Digital palette 仍是独立的产品主题。

## 6. 响应式与平台适配

统一使用三档宽度：Compact `< 600 dp`、Medium `600–1023 dp`、Expanded `≥ 1024 dp`；`≤ 360 dp` 只触发紧凑间距修正。方向是独立布局轴，不创建新路由。

### 6.1 竖屏

- 以三张设计稿的构图和信息层级为基准。
- Flip 卡片纵向排列；Theme 面板从底部进入；Settings 使用单列分组。
- 小屏优先缩放时钟预览，其次压缩非关键间距，不缩小触控区域。

### 6.2 横屏

- Clock 卡片横向排列并尽量利用宽度。
- Theme 面板允许提高最大宽度并减少预览高度；内容仍可滚动。
- Settings 在常规横屏保持单列居中并限制最大内容宽度，避免每行跨度过大。

### 6.3 桌面与 Web

- Clock 继续支持现有全屏能力。
- Theme 面板设置最大内容宽度，宽窗口下不把选项无限拉伸。
- 所有控件提供 hover、focus 和键盘操作状态；焦点轮廓应符合像素语言但不能被裁剪。
- macOS 和 Web 是桌面交互与视觉验收基线；Windows / Linux 保证编译与基本布局可用。
- 窗口缩放时使用同一页面响应式布局，不新增桌面专用路由。

### 6.4 文字缩放

- Settings 和 Theme 至少验证系统文字缩放 `1.0×`、`1.3×`、`2.0×`。
- 长标签允许增加行高或换行；不能缩放文字以强行塞进固定高度。
- 超大文字下 Theme 配色网格可以降为更少列，所有选项仍可通过滚动访问。

## 7. 状态、反馈与无障碍

- 所有交互模块统一覆盖 rest、hover、pressed、focus、selected 和 disabled；pressed 下移 `2 dp` 并缩短硬阴影，不显示圆形水波纹。
- 键盘焦点使用 `pixelFocus` 高对比阶梯描边，不与橙色 selected 描边混淆。
- 正常模式下文字和 Clock 数字对背景至少 `4.5:1`；必要图形、开关边界和焦点框至少 `3:1`。
- Night Mode 的大号时间允许降至 `3:1`，操作 chrome 仍保持 `4.5:1`。
- 主题色样向屏幕阅读器提供名称和选中状态，不能只读出“按钮”。
- Settings 开关应把设置项标签、当前状态和切换动作组合成一个语义节点，避免重复朗读。
- Clock 时间只朗读一次；Flip 重复数字层不进入语义树。
- 装饰性的轴件、阴影、像素角和拖拽指示条不进入语义树。
- Night Mode 沿用当前产品行为：隐藏秒数和日期、降低时钟视觉强度并尝试降低应用亮度；它不等同于 Material 亮暗主题。

## 8. 素材与渲染约束

- 主时钟数字、标签、边框、开关和简单图标优先由 Flutter 文字、ShapeBorder、CustomPainter 或适合硬边的 SVG 绘制。
- 不把整页、Theme 面板、Settings 分组或 Flip 数字导出为位图。
- 必须使用 PNG 的像素素材应提供整数倍率资源，并在显示时使用 `FilterQuality.none`。
- 不使用 Lottie 实现 Flip 翻页；复杂度不足以抵消资源体积、主题适配和动态数字组合成本。
- 图标采用同一网格、描边粗细和切角规则；禁止在同一页面混用默认 Material 圆润图标与像素图标。
- 对发光、渐变和阴影做真机检查，确保低亮度与 OLED 屏幕上仍能看清边界且没有明显色带。

## 9. 实施顺序

### 阶段一：设计系统基础

- 引入 Jersey 25、Pixelify Sans 与 Tiny5，登记固定版本、来源和 OFL 授权，并配置中文系统字体回退链；保留 DSEG7Classic 作为 Digital Display。
- 建立语义颜色、排版、间距、描边、阴影和动画 token。
- 完成 Pixel UI 公开模块与内部几何/交互实现，并从公开接口编写模块级测试。

### 阶段二：Clock 与 Flip

- 将 Flip 卡片外形、数字、AM/PM、中轴和轴件更新为设计稿语言。
- 保留现有时间数据流和翻页算法，补齐减少动态效果分支。
- 验证 12/24 小时、前导零、秒数、日期、Night Mode 及横竖屏组合。
- 统一 Digital、Clock chrome 及 Session running / paused / complete 状态。

### 阶段三：Theme

- 将底部面板、样式选择项和配色网格替换为 Pixel UI 模块。
- 保留即时预览、独立配色记忆和自动持久化行为。
- 补齐小屏、横屏、桌面键鼠与超大字体适配。

### 阶段四：Settings、More 与 About

- 更新页面 chrome、分组容器、分隔线和 Pixel Switch。
- 保留全部设置项、默认值、点击行为和持久化逻辑。
- 完成语义、键盘、触控尺寸及滚动可达性验证。
- 将 More 与 About 纳入同一 PixelSheet / 页面 chrome 体系。

### 阶段五：Splash、Welcome 与视觉校准

- 保留现有插画，替换 Welcome chrome、按钮和分页器，并统一 Splash 动效。
- 在代表性手机、横屏、桌面和 Web 尺寸生成 golden 截图。
- 对照设计稿统一字体基线、切角比例、边框亮度、阴影和间距。
- 检查浅色配色、Night Mode、OLED 低亮度与高文字缩放场景。

## 10. 验收标准

### 视觉一致性

- Splash、Welcome、Clock、Theme、More、Settings、About 和 Session 明确属于同一套 Minimal Pixel UI。
- 所有主要容器使用统一阶梯切角；不存在突兀的默认 Material 圆角控件。
- 文字、图标和边框边缘清晰，没有因插值或模糊导致的发虚。
- 开启、关闭、选中、未选中、按下、悬停和焦点状态均可区分。

### 功能回归

- Flip 和 Digital 可以即时切换并在重启后恢复。
- Flip 的十组配色与 Digital 的九组配色完整、名称正确、互不覆盖。
- 24 Hour、Show Leading Zero、Show Seconds、Date & Weekday、Keep Screen Awake、Night Mode、Sound、Vibration 均保持现有行为和持久化能力。
- Flip 翻页过程中数字连续、层次正确，不发生跳帧、错字或布局位移。
- Night Mode、全屏和 Clock chrome 的既有行为不被像素风改造破坏。

### 适配与无障碍

- 常见手机竖屏、手机横屏、平板、桌面和 Web 窗口均无溢出。
- Theme 和 Settings 在内容超高时可以完整滚动访问。
- 触控目标不小于 `48 × 48 dp`，键盘可遍历所有操作项。
- 在 `2.0×` 文字缩放下功能仍可用，主要文字不截断。
- 屏幕阅读器可以朗读控件名称、当前状态和选中状态。

### 固定回归矩阵

| 基线 | Viewport | 文字缩放 | 重点 |
| --- | --- | --- | --- |
| Android 竖屏 | `360×640` | `1.0×` | 三卡 Flip、Theme、Settings 滚动 |
| iOS 横屏 | `844×390` | `1.3×` | SafeArea、横排 Clock、Theme 滚动 |
| Tablet | `1024×768` | `2.0×` | 网格降列、设置行增高 |
| macOS | `1280×800` | `1.0×` | hover、focus、键盘、全屏 |
| Web | `1440×900` | `2.0×` | 最大宽度、滚动和焦点轮廓 |

Golden 至少覆盖 Flip、Digital、Theme、More、Settings、Welcome 和 About；语义、键盘、滚动与 reduced motion 使用独立交互测试。Windows / Linux 不作为逐像素 golden 基线。

## 11. 范围边界

本方案覆盖当前实际存在的运行时 UI：Splash、Welcome、Clock、Digital、Flip、Clock chrome、Theme、More、Settings、About，以及可恢复的 Session running / paused / complete 状态。开发期间可以短暂并存旧 Material UI，但完成时不得保留可见的旧 Material 控件，也不增加 feature flag。

本方案不包含：

- 新增 Focus / Timer 入口、selector、统计页面、咖啡流程或新的主导航入口；`focus.png` 只作为像素氛围参考。
- 新增 Clock 样式、配色商店、主题下载或付费主题。
- 修改设置数据模型、路由结构或 SharedPreferences 键。
- 自动 Night Mode、环境光感知或系统主题联动。
- 重做现有 Splash / Welcome 插画、应用图标或原生启动图。
- 将横屏实现为独立页面。
- 用整页图片、Lottie 或视频替代可交互 Flutter UI。

后续实现若需要改变上述边界，应先更新产品文档或 ADR，不在视觉改造中隐式扩展。
