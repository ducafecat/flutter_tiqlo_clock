# Tiqlo Settings 像素 UI 样式规范

> 基准实现：[setting.html](./setting.html)  
> 适用范围：Settings 页面及其分组、设置行、像素开关、页面标题与状态栏 chrome。

## 1. 设计原则

- 使用现代移动端布局与像素化几何，不把截图直接作为页面背景。
- 所有像素台阶、描边、阴影和位移必须落在整数 CSS 像素上。
- 阴影不使用 blur；像素层次由独立色块、描边和整数偏移构成。
- 组件使用真实 HTML 控件，整行可点击，键盘焦点可见。
- Settings 固定使用暖黑色 chrome，不跟随 Clock 的彩色主题切换。

### 2.2 字体

字体文件从仓库根目录 `fonts/` 加载，不依赖在线字体服务。

| 角色 | 字体 | 字重 | 字号 |
| --- | --- | --- | --- |
| 页面标题 | Pixelify Sans | 600 | `31px` |
| 分组标题 | Pixelify Sans | 600 | `19px` |
| 设置项 | Pixelify Sans | 400 | `22px` |
| 状态栏时间 | Pixelify Sans | 600 | `24px` |

字体资源：

- `../../fonts/PixelifySans-Regular.ttf`
- `../../fonts/PixelifySans-SemiBold.ttf`

文字渲染规则：

```css
-webkit-font-smoothing: none;
font-smooth: never;
text-rendering: optimizeSpeed;
```

设置项不得使用 `600` 字重，否则笔画会偏粗并改变设计稿的字形气质。

## 4. 像素几何

### 4.1 通用规则

- 不使用普通 `border-radius` 表达像素圆角。
- 使用 `clip-path: polygon(...)` 构造水平、垂直的整数像素台阶。
- Group 使用三套逐级缩小的轮廓：`panel-outer`、`panel-middle`、`panel-inner`。
- Radio 使用独立的 `switch-outer`、中轨、内轨和 `knob-shape`。
- 轮廓点必须保持水平和垂直对称。

### 4.2 Group 分层

Group 不是单层边框加 `drop-shadow`，必须使用以下 DOM 层级：

```text
PixelPanelShell
├── ::before                  1px 右下偏移阴影
└── PixelPanelFrame           2px 深色外框
    └── PixelPanelOutline     2px 暖灰描边
        └── PixelPanelContent 内容裁切层
            └── SettingRow[]
```

尺寸与颜色：

| 层 | 样式 |
| --- | --- |
| 阴影 | `#050504`，`translate(1px, 1px)` |
| 外框 | `2px`，`#0B0A09` |
| 描边 | `2px`，顶部 `#756B5B`，中部 `#5B554B`，底部 `#39352F` |
| 内容 | `#26231F` 暖黑表面 |

### 4.3 设置行分隔线

非末行底部使用独立的 `5px` 像素条：

```text
1px  #100F0D  顶部暗边
2px  #5B554B  暖灰分隔线
2px  #090807  底部硬阴影
```

分隔线由 `SettingRow::after` 绘制，不能使用模糊阴影。

## 5. PixelSwitch（Radio）

### 5.1 尺寸

| 项目 | 数值 |
| --- | --- |
| 控件外框 | `64 × 40px` |
| 黑色外框 | `2px` |
| 中轨内缩 | `2px` |
| 滑块 | `22 × 24px` |
| 滑块左基准 | `7px`（相对中轨） |
| 开启位移 | `24px` |
| 滑块上下视觉留白 | `8px` |
| 滑块左右视觉留白 | `9px` |
| 外部硬阴影 | `translate(1px, 1px)` |

### 5.2 分层

```text
PixelSwitch
├── ::before                  黑色右下阴影
├── ::after                   黑色外框
├── input[type="checkbox"]   原生状态源
└── SwitchTrack               暖灰/橙色描边
    ├── ::before              深色/橙色内轨
    └── SwitchKnob
        ├── ::before          向下 1px 的滑块阴影
        └── ::after           灰色/米白滑块主体
```

### 5.3 滑块轮廓

滑块使用 `22 × 24px` 五段式轮廓：

```text
      ┌──────────┐       10px 顶部平台
   ┌──┘          └──┐    3px 一级台阶
┌──┘                └──┐ 3px 二级台阶
│                      │ 12px 中间直边
└──┐                ┌──┘
   └──┐          ┌──┘
      └──────────┘       10px 底部平台
```

阴影与主体必须使用完全相同的 `clip-path`；阴影层只向下移动 `1px`，不能缩放或使用 blur。

### 5.4 状态

关闭状态：

- 描边：`#5B554B`
- 内轨：`#171612`
- 滑块阴影：`#2B2925`
- 滑块主体：`#55524D`

开启状态：

- 外描边：`#A3480B`
- 内轨主体：`#D96B0C`
- 顶部 `2px` 高光：`#E88A2A`
- 底部 `1px` 暗边：`#B55410`
- 滑块阴影：`#783006`
- 滑块主体：`#F4F0E6`

## 6. 交互与可访问性

- 整个 `SettingRow` 使用 `<label>`，点击文字或空白区域均可切换状态。
- 状态源必须是原生 `<input type="checkbox">`，视觉轨道不能替代语义控件。
- 每个 input 必须有唯一 `name` 和描述性 `aria-label`。
- 键盘焦点使用 `3px` 米白色外框，外偏移 `4px`。
- 开关动画时长 `150ms`，使用 `steps(2, end)` 保持像素跳变感。
- 系统启用 `prefers-reduced-motion` 时关闭轨道与滑块动画。

## 8. 验收清单

- [ ] 页面在 `426 × 923px` 视口中无横向溢出。
- [ ] Pixelify Sans 本地字体加载成功，设置项使用 `400`。
- [ ] Group 四层结构完整，右下阴影仅偏移 `1px`。
- [ ] 分隔线为 `1 + 2 + 2px` 三段结构。
- [ ] Radio 尺寸为 `64 × 40px`。
- [ ] 滑块尺寸为 `22 × 24px`，轮廓上下、左右对称。
- [ ] 滑块两端位置的留白一致。
- [ ] 所有阴影均为硬边且无 blur。
- [ ] 开启和关闭状态不仅依赖颜色，还通过滑块位置区分。
- [ ] 整行可点击，键盘焦点清晰可见。
