# 03: 时间显示设置

**What to build:** Settings 里可改 12/24 小时制、是否显示秒。12 小时制必显 AM/PM。显示秒时墙上时间对齐下一秒跳；关闭秒时对齐下一分钟。默认跟随设备 12/24 制。改完记住，重启还在。About 显示版本号。

**Blocked by:** 02 Clock 外壳

**Status:** ready-for-agent

- [x] 12 小时制显示 AM/PM；24 小时制不显示
- [x] 默认跟随设备时间制，用户可改并持久化
- [x] 开秒：墙上时间每秒跳；关秒：整分才跳，且不每秒 rebuild 整页
- [x] 重启后时间制和秒开关仍在
- [x] About 能看到版本号
